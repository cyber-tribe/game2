# ゴッドゲーム システム調査資料

1980年代末に確立された「神視点リアルタイム戦略ゲーム（ゴッドゲーム）」の
ゲームシステムを調査し、本プロジェクトで再現するための仕様としてまとめる。

プレイヤーは神として世界に介入し、自分を信仰する民を間接的に導いて、
敵対する神の民と世界の覇権を争う。ユニットを直接操作することはできず、
「地形の操作」と「奇跡（パワー）」と「大まかな行動方針の指示」だけで
民を繁栄させ、敵勢力を殲滅することが目的となる。

---

## 1. ゲームの基本ループ

```
地形を平らに整える
      ↓
民が平地に家を建てる
      ↓
人口が増え、信仰エネルギー（マナ）が蓄積する
      ↓
マナを使ってさらに地形を整える／奇跡を起こす
      ↓
（繰り返し。最終的に敵勢力を全滅させる）
```

- ゲームは**リアルタイム**で進行する。敵AIも同時に同じ手段で介入してくる。
- 自陣営と敵陣営の2勢力。民は自動で行動し、直接命令はできない。

## 2. 世界（マップ）

- 見下ろし型の**アイソメトリック（クォータービュー）表示**。
- 地形は格子状で、**タイルの四隅（頂点）ごとに高さ**を持つ。
  高さ0が海面で、海には建物を建てられず、通常の民は入ると溺れる。
- 画面には世界の一部だけが表示され、スクロールで移動する。
  全体はミニマップ（世界儀）で俯瞰できる。
- **地形タイプ**が複数あり（草原、砂漠、雪原、岩・溶岩地帯など）、
  見た目だけでなく民の成長速度などに影響する
  （例：草原は標準、砂漠は成長が遅い、溶岩地帯はさらに過酷）。

## 3. 地形操作

- 最も基本の介入。**頂点を1段上げる／下げる**ことができ、少量のマナを消費する。
- 主目的は民のために**平地を作る**こと。平地が広いほど大きな建物が建つ。
- 逆に敵集落の周囲の地形を崩して妨害することもできる。
- 起伏の多い土地では小さく原始的な集落が多数でき（拡張は速いが弱い）、
  広い平地では大きく発達した集落になる（拡張は遅いが強固）、
  という戦略上のトレードオフがある。
- **自動整地**：自分の家をタップすると、その家を中心に7x7マスを一度に
  均す。原作の「Xボタンで建物を中心に7x7マスの平地を確保」に対応する。
  値段は手作業と同じ（実際に動くタイル1枚につき地形操作1回分）で、
  すでに平らなら無料。整地の割引ではなく操作の近道である。

## 4. 民（ウォーカー）

- マップ上を歩き回る自律ユニット。各ウォーカーは内部に「人数／強さ」を持ち、
  見た目は1人でも実際は集団を表す。
- 行動は自動：平地を探して**定住**し家を建てる、家が満杯になると
  新しいウォーカーが輩出される、など。
- 同勢力のウォーカー同士が出会うと**合流して1体の強いウォーカーになる**ことができる。
- 敵ウォーカーと接触すると**戦闘**になり、強さの高い方が勝ち残る。
- 敵の家に入ると戦闘の末、**家を奪う（自陣営化する）**か破壊する。
- 水に入ると溺れて死ぬ（後述のヒーロー（騎士・守護者）や、特殊な状況を除く）。
- 沼に入ると沈んで死ぬ。

### リーダー

- 自陣営のウォーカーのうち1体が**リーダー**となる（集結シンボルに最初に
  触れた者など）。リーダーは旗などで区別して表示される。
- 「集結」系の指示では民はリーダーの元へ向かい、リーダーは
  **集結シンボル**（後述）へ向かう。
- リーダーは奇跡「騎士化」「守護者化」の対象となる（ヒーローの種類は
  8節参照）。

## 5. 集落（家）

- ウォーカーが平地に定住すると**家**を建てる。
- 家は**周囲の平地の広さに応じて段階的に発達**する：
  小屋 → 中規模の家 → 大きな家 → 城砦（最大）。
  周囲の地形をさらに平らにすると自動でアップグレードされる。
- 家の周囲は**農地**になり、視覚的に勢力圏を示す。
- 家は時間とともに**人口を生産**し、満杯になると新しいウォーカーを外に出す。
  大きな家ほど生産が速く、マナ供給も多い。
- 地震などで周囲の地形が崩れると家はダウングレード／破壊される。
- **スプログ**：自分の家をタップすると、その家の信者の**一部**が即座に
  外へ出る。原作の「建物の中心にカーソルを合わせてBボタンを押すと、
  信者の一部が追い出される」に対応する。満杯を待たずに拡張へ回せるのが
  目的で、原作でも「前作に無かった仕様で、ゲームの進行が早くなった」と
  評価された点である。マナは要らない。
  - 出ていくのは残っている人口の半分で、家は残りを抱えたまま成長を続ける。
    押すたびに取り分が減るので、一定割合を下回ると断られる。
  - 出たウォーカーは、満杯まで待って生まれるウォーカーより**弱い**。
    早く多く得る代わりに1体あたりが弱い、というトレードオフ。

## 6. マナ（信仰エネルギー）

- プレイヤーの介入コストを支払う唯一の資源。ゲーム開始時は0。
- **信者の総人口に比例して自動蓄積**する。大きな集落（城砦）ほど供給が多い。
- 画面上に**マナゲージ**があり、ゲージ上に各奇跡のアイコンが並ぶ。
  - 左端＝最少コスト（地形の上げ下げ）、右端＝最大コスト（最終決戦）。
  - マナが各アイコンの閾値に達すると、その奇跡が**解禁**される。
  - 使用するとマナが減り、高位の奇跡は再び蓄積するまで使えない。
- 人口が多いほど蓄積が速い＝人口拡大がそのまま介入力の拡大につながる。

## 7. 行動方針の指示（影響）

民に与えられる大まかな行動モード。**マナ消費なし**で常にいずれか1つが
有効になっている。

| モード | 効果 |
|---|---|
| 定住 | 最寄りの平地へ向かい、家を建てて人口を増やす（標準の拡大方針） |
| 集結 | ウォーカー同士が合流し、少数の強いウォーカーにまとまる |
| 集結シンボルへ | 民はリーダーへ、リーダーはシンボルへ向かう（軍勢の誘導） |
| 戦闘 | 敵のウォーカー・家を積極的に探して攻撃する |

- 「集結してから定住」「戦闘してから定住」のような複合指示もある。
- **集結シンボル**は自陣営の信仰の対象となる像で、奇跡によって
  マップ上の任意の場所（自勢力の影響範囲）へ移動できる。
  敵地にシンボルを置き「シンボルへ」を指示することで侵攻を誘導する。

原作は「集結」と「集結シンボルへ」を1つの指示（集合）として説明しており、
game2はそれを2つに分けている。分けても次の3点は原作通りにする。

- **集結中は家を建てない。** 原作は「その間、平地があっても新たな建物は
  一切建てない」と明記している。行軍が定住に化けてはいけない。
- **リーダーはシンボルに最初に着いた者がなる。** どちらの指示で行かせたか
  ではなく、着いたことで決まる。リーダーが居なければ全員がシンボルへ
  向かい、最初に着いた者が昇格する（指示が自力で始動できる）。
- **どちらの指示でも合流する。** 合流こそがこの指示を出す理由であり、
  原作も「多数の信者を合体させ、強力なヒーローを生み出すのに不可欠な
  操作である」と書いている。

## 8. 奇跡（パワー）一覧

### 撃てる範囲

- 奇跡（地形の上げ下げを含む）は、**いま画面に映っている場所にしか撃てない**。
  さらに、**自分の民・家・集結地のどれかが同時に画面に映っていなければ**
  撃てない。原作のクローズアップマップの制約
  （「現在、見えているクローズ・アップ・マップの範囲に」）に対応する。
- 距離ではなく**画面**の制約である点が肝で、自陣を画面の端に残したまま
  反対の端へ撃てば、勢力の前方へ射程を伸ばせる。前線を進めることが
  そのまま神の手の届く範囲を広げることになる。
- アイソメトリック表示なので、画面はタイル空間では**細長い菱形**になる。
  奥行き方向（画面の縦）には遠くまで届き、横方向にはほとんど届かない。
- **敵の神も同じ制約を受ける。** 敵には画面が無いが、同じ形・同じ大きさの
  仮想的な視界を持ち、「その視界に自分の勢力が居て、かつ標的も入って
  いる」場合にのみ奇跡を撃つ。マナだけ貯めて地図の反対側を叩くことは
  できない。

コストの低い順。効果と用途を示す。

> **これは game2 が現在持っている奇跡の一覧であって、原作の全体像ではない。**
> 原作『POPULOUS 2』は6系統29個の奇跡を持ち、その本質は個々の効果ではなく
> 奇跡どうし・地形・英雄の**相互作用**にある。原作側の仕様と、この表との
> 差分は `docs/original-miracles.md` にまとめてある。

| 奇跡 | コスト | 効果 |
|---|---|---|
| 地形上げ／下げ | 極小 | 頂点1つの高さを変更。序盤から常用する基本操作 |
| 集結シンボル移動 | 小 | シンボルを指定地点へ移動し、軍勢の目標地点を変える |
| 地震 | 中 | 集結シンボルから見て指定地点の向こうへ、長い地割れを走らせる。地割れに入った民は死に、埋め戻すまで残る。その上には建築できない |
| 病原菌 | 中 | 対象範囲の民と家を感染させる。**誰も死なず、何も壊れない**——感染した家はマナを産まず、感染した民は最終決戦に参加しない。接触で周囲へ広がり、一定時間で治る。陣営を区別しないので自軍にも移る |
| 沼 | 中 | 対象地点に沼を生成。踏み込んだ民は騎士・守護者を含め沈んで死ぬ。一定数を飲み込むと消えるタイプと恒久のタイプがある |
| 聖水の泉 | 大 | 対象地点に泉を湧かせる。**敵の民が入ると自軍へ寝返る**。英雄も寝返るので、強い英雄を奪えば形勢が逆転する。一定数を取り込むと涸れる。互いに泉を持てば、同じ民が何度も行き来する |
| 守護者化 | 中〜大 | 自軍リーダーを守護者に変える。守護者は自軍の集落の近くに脅威（敵ウォーカー・家）が現れたときだけ迎撃に向かい、奪った家は焼かず占領して生き延びる。脅威がなければ持ち場で待機する、専守防衛タイプのヒーロー。ただし沼には他の民と同様に沈む。**原作にはない game2 独自の英雄**（平坦化と同じ位置づけ） |

| トロイのヘレン | 中〜大 | 自軍リーダーをヘレンに変える。**敵と戦わない**——家も民も傷つけられない。代わりに近づいた敵の民を魅了して拘束し、連れ回す。拘束された民は自軍のために何もしなくなり、家も建てない。**ヘレンが死ぬと拘束は解ける**。同時に拘束できる人数には上限があり、あぶれた敵に触れられると彼女は死ぬ |
| アドニス | 大 | 進軍の仕方はペルセウスと同じだが、**戦闘に勝つたびに2体へ分裂する**（それぞれ体力は半分）。分裂しすぎると弱い英雄が増え、英雄が死ぬたびにマナを失う |
| ヘラクレス | 大 | 進軍の仕方はペルセウスと同じだが、**戦闘力が2倍**で、**地割れに落ちない**。荒らされた地図を渡れる唯一の英雄 |
| オディッセウス | 中〜大 | 進軍の仕方はペルセウスと同じだが、**移動速度が1.8倍**。道の上ではさらに速い |
| アキレス | 大 | 進軍の仕方はペルセウスと同じだが、**火で焼死しない**。火の雨や延焼した森の中を歩ける |
| 火山 | 大 | 対象地点を高く隆起させ、火口から溶岩を流す。溶岩は低い方へ流れて広がるが、水地形で止まる。覆われた土地には建築できず、復旧には大量の地形操作が必要 |
| 花 | 小 | 対象範囲の荒れた土地を元に戻す。地割れを埋め、火山の岩と溶岩を消し、火柱の焼け跡を戻し、沼を枯らす。**地震・火山・火柱・沼への対抗手段** |
| 森 | 小 | 対象地点の周囲に木を生やす。森の中の家は人口の増えが速い。ただし森はよく燃える |
| 竜巻 | 中 | 発動地点から一定時間さまよう。巻き込んだ民を中心へ引きずりながら体力を削る（家には触れない）。**水地形へ入ると渦巻きへ変わる** |
| 渦巻き | — | 奇跡としては撃てない。**竜巻が海へ入ったときだけ生まれる**。海上を移動しながら触れた陸地を海面まで削り、そこに居た民と家を沈める。一定時間ごとに分裂して被害範囲が広がる |
| 雷 | 中 | 指定地点の**周辺**へ複数の落雷。人は死に、家は焼け、地面は荒地になる。**狙った所ちょうどには落ちない**（散らばる）のがこの奇跡の性格 |
| 嵐 | 大 | 指定地点に雷雲を留め、一定時間そこへ落雷し続ける。家を壊し地面を荒地にするが、**人には当たらない**。土地を使えなくする奇跡 |
| 火柱 | 中〜大 | 集結地から見て指定地点の向こうへ、さまよう火柱を立てる。触れた民は焼死し、家は崩れ、**通った地面は荒地になって建築できなくなる**（花で戻せる）。アキレスだけは焼死しない |
| ハリケーン | 中〜大 | 集結地から見て指定地点の向こうへ、細長い強風を一度だけ吹かせる。回廊内の家を壊し、民を風下へ吹き飛ばす。**それ自体では誰も殺さない**——飛ばした先に沼や亀裂があれば死ぬ |
| 火の雨 | 中 | 対象範囲に火を降らせ、民を殺し家を焼く。**森に落ちると森づたいに延焼し、範囲を遥かに超えて広がる** |
| 道 | 小 | 対象範囲を舗装する。上を歩く民の移動が速くなり、**毒カビはこれを越えられない**。毒カビの上には敷けない |
| 城壁 | 小 | 対象地点に石壁の塊を築く。**民は越えられず、英雄だけが越える**。一度の詠唱で築けるのは小さな塊なので、線にするには繋げて撃つ。水・亀裂・毒カビの上には築けない。**地震の地割れと火山の溶岩が壊す** |
| 地下巨石 | 中 | 対象地点の地面を大きく隆起させ、冷たい岩の塊を起こす。**建てられない上、周りの平地も壊すので大きな家が建たなくなる**。上に建っていた家は壊れるが、**人は死なない**。修復手段は無く、**海面まで掘り下げて沈めたときだけ消える** |
| 毒カビ | 小 | 対象地点にカビを撒く。放置すると勝手に増殖し、届いた民と家を飲み込む。密集させるほど速く広がり、まばらなものは自然消滅する。**道で進行を止められる** |
| 岩礁 | 小 | 海上に岩を線分状に隆起させる。建築はできないが津波を砕く。1キャストでは波が回り込むので、海岸を塞ぐには何度か並べる |
| 津波 | 特大 | 発動地点から波が広がり、届いた低地を水没・侵食する。波の全高を超える地形と岩は波を止め、その背後を守る。海面自体は変わらない |
| 最終決戦 | 最大 | 両陣営の集結シンボルが世界の中央へ移動し、全ての民が家を捨てて中央に集まり、総力戦を行う。勝った陣営がゲームに勝利する。人口で明確に勝っているときの「決着ボタン」。**この行進だけはリーダーを介さない**——民は中央そのものへ向かう（通常の「集結シンボルへ」はリーダー追従） |

**英雄が死ぬと、その陣営はマナを失う。** 英雄は投資であり、失えば代償がある
（アドニスを増やしすぎたときの歯止めでもある）。

## 9. 勝敗条件

- **勝利**：敵陣営の民と家をすべて消滅させる（または最終決戦で勝つ）。
- **敗北**：自陣営の民が全滅する。
- 引き分けはなく、決着までリアルタイムで争いが続く。

## 10. キャンペーン構造

- 約500の固定ワールドを順に攻略していく**征服モード**が本編。
- 各ワールドは地形タイプ・初期配置・敵AIの攻撃性／賢さ・
  使用可能な奇跡の制限などが異なり、徐々に難しくなる。
- クリアすると**パスワード（ワールド名）**が与えられ、そこから再開できる。
  勝ち方の内容（残存人口など）に応じて数ワールド先へスキップできる。
- 別途、設定をカスタムして1戦だけ遊ぶモードや、2人対戦モードを持つ。

### 敵AI

- **敵の神はワールドごとに系統（人・植物・地・気・火・水）を持つ。**
  その系統の代表的な奇跡を繰り返し撃ってくる——火の神は集落へ火の雨を、
  水の神は聖水の泉で民を奪う、という具合に。撃てるのはそのワールドが
  解禁している奇跡だけで、代表の奇跡が高いときは**貯まるまで待つ**
  （安い地震で埋め合わせない）。系統が解禁されていないワールドでは
  地震に落ちる。系統は世界選択画面に表示される。
- **敵は出撃前に軍を編成する。** 家を奪うには奪う側の強さが家の防御力を
  上回る必要があり（小屋3・中規模6・大きな家12・城砦20）、民は強さ1で
  生まれる。強さを足し合わせられるのは集結だけなので、敵は出撃条件を
  満たしても「相手の一番弱い家を奪える民」ができるまで集結を続け、
  できてから戦闘へ移る。攻め込まれているときは編成を待たずに応戦する。
- 敵の神はプレイヤーと同じルールで介入する。奇跡を撃てる範囲も同じで、
  自分の勢力と標的が1つの視界に収まるときにしか撃てない（8節「撃てる範囲」）。
  ワールドごとに
  「攻撃性」「賢さ」「介入速度」などのパラメータが設定され、難易度を形成する。
- 高難度では敵の介入頻度が上がるが、行動パターン自体は比較的予測可能。
- 上記は純粋な数値の難易度調整だが、それとは別に**気質**という軸を持つ。
  「好戦的」は少ない優勢でも火山・最終決戦に踏み切り、劣勢が明白な
  ときだけ守護者で守りを固める。「専守防衛」は逆に、優勢が固まる
  までなかなか踏み切らず、守護者に頼りがちになる。「堅実」は
  従来通りの基準値のまま。気質は難易度のように単調に厳しくなる軸
  ではなく、ワールドごとに「違う相手と対戦している」感覚を出すための
  ものであり、世界選択画面にも表示される。

## 11. UI 要素

- **メイン画面**：アイソメトリック表示の世界。クリックで地形操作。
- **世界儀（ミニマップ）**：世界全体の俯瞰。クリックで視点移動。
- **マナゲージ**：現在のマナ量と、解禁済み奇跡のアイコン列。
- **奇跡パネル**：原作と同じ6系統（人・植物・地・気・火・水）のタブで、
  **一度に1系統ぶん（最大5個）だけ**を表示する。29個を1つの格子に
  並べると探せなくなるため。系統を切り替えると選択中の奇跡は解除され
  照会へ戻る（見えていない奇跡が構えたままになるのを避ける）。
  隆起・沈降・平坦化は系統に入れず常時表示——このゲームの基本ループ
  そのものなので、1タップ余計にかかると割に合わない。
- **情報パネル**：任意のウォーカー・家を照会して人数／強さ／
  発達段階を確認できる。両陣営の総人口の比較表示もある。
- **行動方針パネル**：定住／集結／シンボルへ／戦闘の切り替えアイコン。

## 12. 実装に向けたデータモデルの素案

```
World
  ├ tiles[w][h]        … 頂点高さマップ (0=海面)
  ├ terrainType        … 草原/砂漠/雪原/溶岩 (成長係数)
  └ waterLevel         … 洪水で上昇する海面高さ

Faction (player / enemy)
  ├ mana               … 蓄積エネルギー
  ├ behaviorMode       … 定住/集結/シンボルへ/戦闘
  ├ shrinePosition     … 集結シンボルの座標
  └ leaderId           … リーダーのウォーカーID

Walker
  ├ faction, pos
  ├ strength           … 内部人数/戦闘力
  └ state              … 移動/定住/戦闘/騎士/守護者 など

House
  ├ faction, pos
  ├ level              … 小屋〜城砦
  └ population         … 蓄積人口 (満杯でウォーカー輩出、マナ供給量はレベル別
                          上限値にpopulation/capacityを掛けた分だけ発生)

Simulation (tick駆動)
  ├ ウォーカーAI (探索/建築/合流/戦闘)
  ├ 家の成長/人口生産
  ├ マナ蓄積
  └ 敵神AI (地形操作/奇跡の使用)
```
