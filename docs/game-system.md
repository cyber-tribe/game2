# ゴッドゲーム システム調査資料

1980年代末に確立された「神視点リアルタイム戦略ゲーム（ゴッドゲーム）」の
ゲームシステムを調査し、本プロジェクトで再現するための仕様としてまとめる。

プレイヤーは神として世界に介入し、自分を信仰する民を間接的に導いて、
敵対する神の民と世界の覇権を争う。ユニットを直接操作することはできず、
「地形の操作」と「奇跡（パワー）」と「大まかな行動方針の指示」だけで
民を繁栄させ、敵勢力を殲滅することが目的となる。

---

## 1. ゲームの基本ループ

```
地形を平らに整える
      ↓
民が平地に家を建てる
      ↓
人口が増え、信仰エネルギー（マナ）が蓄積する
      ↓
マナを使ってさらに地形を整える／奇跡を起こす
      ↓
（繰り返し。最終的に敵勢力を全滅させる）
```

- ゲームは**リアルタイム**で進行する。敵AIも同時に同じ手段で介入してくる。
- 自陣営と敵陣営の2勢力。民は自動で行動し、直接命令はできない。

## 2. 世界（マップ）

- 見下ろし型の**アイソメトリック（クォータービュー）表示**。
- 世界は黒い虚空に浮かぶ**一枚の板**として描かれる。板の切り口には
  **地層**が見える——縁のすぐ下に明るい表土、その下に茶色い土、いちばん
  下に黒に近い岩盤。地表に何が生えていようと切り口は同じ土であり、
  地表の色をそのまま下へ押し出したものではない。
- 地形は格子状で、**タイルの四隅（頂点）ごとに高さ**を持つ。
  高さ0が海面で、海には建物を建てられず、通常の民は入ると溺れる。
- 画面には世界の一部だけが表示され、スクロールで移動する。
  全体はミニマップ（世界儀）で俯瞰できる。
- **世界の左右にも、同じ虚空に浮かぶ構造物がある。** 左上に世界地図を載せた
  岩盤、右上に円形劇場。どちらも画面の隅に貼られたHUDではなく、世界と同じ
  空間に置かれた物として描かれる。円形劇場は客席の色分けで両勢力の
  勢いを示し、優勢・劣勢が遠目でも分かる。
- **地形タイプ**が複数あり（草原、砂漠、雪原、岩・溶岩地帯など）、
  見た目だけでなく民の成長速度などに影響する
  （例：草原は標準、砂漠は成長が遅い、溶岩地帯はさらに過酷）。

## 3. 地形操作

- 最も基本の介入。**頂点を1段上げる／下げる**ことができ、少量のマナを消費する。
- 主目的は民のために**平地を作る**こと。平地が広いほど大きな建物が建つ。
- 逆に敵集落の周囲の地形を崩して妨害することもできる。
- 起伏の多い土地では小さく原始的な集落が多数でき（拡張は速いが弱い）、
  広い平地では大きく発達した集落になる（拡張は遅いが強固）、
  という戦略上のトレードオフがある。
- **自動整地**：自分の家をタップすると、その家を中心に7x7マスを一度に
  均す。原作の「Xボタンで建物を中心に7x7マスの平地を確保」に対応する。
  値段は手作業と同じ（実際に動くタイル1枚につき地形操作1回分）で、
  すでに平らなら無料。整地の割引ではなく操作の近道である。
- **面ごとに地形操作が制限されることがある。** 原作記事は3種を挙げている
  ——「土地上げ不可ステージ」「土地下げ不可ステージ」「土地上下不可
  ステージ」。game2 の `TerrainEditRule` がこれで、上下とも封じられた面
  では隆起・沈降だけでなく平坦化・自動整地も使えない（どれも同じ頂点編集で
  できているため）。残るのは既にある平地に建てることと、奇跡である
  ——記事も「よって神業で敵の住める土地をゼロにすることになる」と書く。
  制限は敵にも等しくかかる。

## 4. 民（ウォーカー）

- マップ上を歩き回る自律ユニット。各ウォーカーは内部に「人数／強さ」を持ち、
  見た目は1人でも実際は集団を表す。
- 行動は自動：平地を探して**定住**し家を建てる、家が満杯になると
  新しいウォーカーが輩出される、など。
- 同勢力のウォーカー同士が出会うと**合流して1体の強いウォーカーになる**ことができる。
- 敵ウォーカーと接触すると**戦闘**になり、強さの高い方が勝ち残る。
- 敵の家に入ると戦闘の末、**家を奪う（自陣営化する）**か破壊する。
- 水に入ると溺れて死ぬ（後述のヒーロー（騎士・守護者）や、特殊な状況を除く）。
- 沼に入ると沈んで死ぬ。

### リーダー

- 自陣営のウォーカーのうち1体が**リーダー**となる（集結シンボルに最初に
  触れた者など）。リーダーは旗などで区別して表示される。
- 「集結」系の指示では民はリーダーの元へ向かい、リーダーは
  **集結シンボル**（後述）へ向かう。
- **集結中、マグネットに着いたリーダーは青い炎に包まれ無敵になる。**
  原作は「リーダーがマグネットに到達すると、その場に停止して青い炎に
  包まれます（この間は無敵状態になります）」と書く。攻撃神技も戦闘も
  通らない。ただし守られるのはリーダー1人だけで、集まってくる民は守られ
  ない——原作は地震の項でその代償を書いている。「集まってくるウォーカーが
  次々に地割れに落ちていくため、集合を解除することが多い。その瞬間に
  リーダーも地割れに落ちる」。集結は攻めの指示であると同時に守りの指示で
  あり、いつ解くかが判断になる。
- **英雄になるとリーダーではなくなり、集結シンボルはリーダーが立っていた
  場所に残る。** 原作は6英雄すべての説明に同じ一文を置いている——「影響で、
  味方リーダーがいなくなる。マグネットはリーダーのいた場所に移動する」。
  結果として、英雄を出した陣営はシンボルを動かせなくなり、もう一度「集結」
  で次のリーダーを立てるまで待つことになる。英雄の再専門化（ペルセウスを
  ヘラクレスに変える）も起きない——英雄はもうリーダーではないからである。
- リーダーは奇跡「騎士化」「守護者化」の対象となる（ヒーローの種類は
  8節参照）。

## 5. 集落（家）

- ウォーカーが平地に定住すると**家**を建てる。
- 家は**周囲の平地の広さに応じて段階的に発達**する：
  小屋 → 中規模の家 → 大きな家 → 城砦（最大）。
  周囲の地形をさらに平らにすると自動でアップグレードされる。
- 家の周囲は**農地**になり、視覚的に勢力圏を示す。
- 家は時間とともに**人口を生産**し、満杯になると新しいウォーカーを外に出す。
  大きな家ほど生産が速く、マナ供給も多い。
- 地震などで周囲の地形が崩れると家はダウングレード／破壊される。
- **スプログ**：自分の家をタップすると、その家の信者の**一部**が即座に
  外へ出る。原作の「建物の中心にカーソルを合わせてBボタンを押すと、
  信者の一部が追い出される」に対応する。満杯を待たずに拡張へ回せるのが
  目的で、原作でも「前作に無かった仕様で、ゲームの進行が早くなった」と
  評価された点である。マナは要らない。
  - 出ていくのは残っている人口の半分で、家は残りを抱えたまま成長を続ける。
    押すたびに取り分が減るので、一定割合を下回ると断られる。
  - 出たウォーカーは、満杯まで待って生まれるウォーカーより**弱い**。
    早く多く得る代わりに1体あたりが弱い、というトレードオフ。

## 6. マナ（信仰エネルギー）

- プレイヤーの介入コストを支払う唯一の資源。ゲーム開始時は0。
- **信者の総人口に比例して自動蓄積**する。大きな集落（城砦）ほど供給が多い。
- **総人口には野に出ている信者も含む。** 原作は「マナは信者数と時間経過に
  応じて蓄積される」と書いており、家に居るかどうかは条件になっていない。
  外に出た信者は小屋に居たときと同じ量を産む（`FOLLOWER_MANA_RATE`）ので、
  集結もスプログも収入を落とさない。ただし小屋と同じ上限
  （`HUT_MANA_RATE_CAP`）の内側で数えるので、全員を外に出すことが
  家をレベルアップさせるより得になることはない。
- **合流しても人口は減らない。** ウォーカーの強さはそのまま人数であり
  （`population.ts` の `walkerFollowers`）、8人が1体になっても8人と数える。
  「多数の信者を合体させ、強力なヒーローを生み出す」指示が、人口と収入を
  削る指示であってはならない。
- 画面上に**マナゲージ**があり、ゲージ上に各奇跡のアイコンが並ぶ。
  - 左端＝最少コスト（地形の上げ下げ）、右端＝最大コスト（最終決戦）。
  - マナが各アイコンの閾値に達すると、その奇跡が**解禁**される。
  - 使用するとマナが減り、高位の奇跡は再び蓄積するまで使えない。
- 人口が多いほど蓄積が速い＝人口拡大がそのまま介入力の拡大につながる。

## 7. 行動方針の指示（影響）

民に与えられる大まかな行動モード。**マナ消費なし**で常にいずれか1つが
有効になっている。

| モード | 効果 |
|---|---|
| 定住 | 最寄りの平地へ向かい、家を建てて人口を増やす（標準の拡大方針）。歩き回る向きは一様ではなく、**マップ中央より端へ向かいやすい**（原作の「マップ中央よりは端に向かいやすい傾向があります」） |
| 集結 | ウォーカー同士が合流し、少数の強いウォーカーにまとまる |
| 合体 | 近くの味方ウォーカーへ向かって合流し、力を増す。近くに誰も居なければ定住と同じ |
| 集結シンボルへ | 民はリーダーへ、リーダーはシンボルへ向かう（軍勢の誘導） |
| 戦闘 | 敵のウォーカー・家を積極的に探して攻撃する |

- 「集結してから定住」「戦闘してから定住」のような複合指示もある。
- **集結シンボル**は自陣営の信仰の対象となる像で、奇跡によって
  マップ上の任意の場所（自勢力の影響範囲）へ移動できる。
  敵地にシンボルを置き「シンボルへ」を指示することで侵攻を誘導する。

**合体は集結の別名ではない。** 原作は4つの神の啓示（集合・合体・戦闘・
定住）を並べており、合体は「近くにいる信者達と合体し、その力を増して
いく。近くに他の信者がいない場合は定住に同じ」である。集結との違いは
2つあり、どちらも重要である。

- **行き先が場所ではなく人である。** 集合はシンボルへ全員を集める。
  合体は互いへ向かうだけで、シンボルもリーダーもヒーロー変身も無い。
- **経済が止まらない。** 集結中は家を一切建てないが、合体は建てる。
  合体相手が近くに居なくなった民はそのまま定住に落ちる——「定住に同じ」
  とはこのことで、特別扱いではなく「何もしない」の結果である。

合体は集結より安全で遅い強化手段になる。旗を立てる必要が無く拡大も
止まらない代わりに、リーダーもヒーローも出ない。

原作は「集結」と「集結シンボルへ」を1つの指示（集合）として説明しており、
game2はそれを2つに分けている（モードが4つではなく5つあるのはこのため）。
分けても次の3点は原作通りにする。

- **集結中は家を建てない。** 原作は「その間、平地があっても新たな建物は
  一切建てない」と明記している。行軍が定住に化けてはいけない。
- **リーダーはシンボルに最初に着いた者がなる。** どちらの指示で行かせたか
  ではなく、着いたことで決まる。リーダーが居なければ全員がシンボルへ
  向かい、最初に着いた者が昇格する（指示が自力で始動できる）。
- **どちらの指示でも合流する。** 合流こそがこの指示を出す理由であり、
  原作も「多数の信者を合体させ、強力なヒーローを生み出すのに不可欠な
  操作である」と書いている。

## 8. 奇跡（パワー）一覧

### 撃てる範囲

- 奇跡（地形の上げ下げを含む）は、**いま画面に映っている場所にしか撃てない**。
  さらに、**自分の民・家・集結地のどれかが同時に画面に映っていなければ**
  撃てない。原作のクローズアップマップの制約
  （「現在、見えているクローズ・アップ・マップの範囲に」）に対応する。
- 距離ではなく**画面**の制約である点が肝で、自陣を画面の端に残したまま
  反対の端へ撃てば、勢力の前方へ射程を伸ばせる。前線を進めることが
  そのまま神の手の届く範囲を広げることになる。
- アイソメトリック表示なので、画面はタイル空間では**細長い菱形**になる。
  奥行き方向（画面の縦）には遠くまで届き、横方向にはほとんど届かない。
- **敵の神も同じ制約を受ける。** 敵には画面が無いが、同じ形・同じ大きさの
  仮想的な視界を持ち、「その視界に自分の勢力が居て、かつ標的も入って
  いる」場合にのみ奇跡を撃つ。マナだけ貯めて地図の反対側を叩くことは
  できない。

コストの低い順。効果と用途を示す。

> **これは game2 が現在持っている奇跡の一覧であって、原作の全体像ではない。**
> 原作『POPULOUS 2』は6系統29個の奇跡を持ち、その本質は個々の効果ではなく
> 奇跡どうし・地形・英雄の**相互作用**にある。原作側の仕様と、この表との
> 差分は `docs/original-miracles.md` にまとめてある。

| 奇跡 | コスト | 効果 |
|---|---|---|
| 地形上げ／下げ | 極小 | 頂点1つの高さを変更。序盤から常用する基本操作 |
| 集結シンボル移動 | 小 | シンボルを指定地点へ移動し、軍勢の目標地点を変える。**リーダーが居ないと使えない**——シンボルはリーダーのものであり、率いる者が居なければ動かすものが無い。侵攻はまず「集結」から始まる |
| 地震 | 中 | 集結シンボルから見て指定地点の向こうへ、長い地割れを走らせる。地割れに入った民は死に、埋め戻すまで残る。その上には建築できない。**地割れ沿いの地面はしばらく揺れ続け、その間は土地上下・平坦化・自動整地が効かない**（原作「地震が続いている間は修復が出来ない」）。花なら揺れていても埋められる |
| 病原菌 | 中 | 対象範囲の民と家を感染させる。**誰も死なず、何も壊れない**——感染した家はマナを産まず、感染した民は最終決戦に参加しない。接触で周囲へ広がり、一定時間で治る。陣営を区別しないので自軍にも移る |
| 沼 | 中 | 対象地点に沼を生成。踏み込んだ民は沈んで死ぬ（**アドニスだけは沈まない**——植物の英雄なので）。**1人飲み込むと埋まって普通の地面に戻る**タイプと、**底なし沼**（決して埋まらず消えない）があり、**どちらになるかは面ごとに決まる**。埋まる方は1人ぶんの罠なので、集落へ撒くのではなく歩いてくるリーダーに置くものである。原作48面のうち底なしでないのは5面だけ（`docs/original-maps.md`）。敵の神の沼も同じ面では同じ種類になる |
| 聖水の泉 | 大 | 対象地点に泉を湧かせる。**敵の民が入ると自軍へ寝返る**。英雄も寝返るので、強い英雄を奪えば形勢が逆転する。一定数を取り込むと涸れる。互いに泉を持てば、同じ民が何度も行き来する |
| 守護者化 | 中〜大 | 自軍リーダーを守護者に変える。守護者は自軍の集落の近くに脅威（敵ウォーカー・家）が現れたときだけ迎撃に向かい、奪った家は焼かず占領して生き延びる。脅威がなければ持ち場で待機する、専守防衛タイプのヒーロー。ただし沼には他の民と同様に沈む。**原作にはない game2 独自の英雄**（平坦化と同じ位置づけ） |
| ペルセウス | 大 | 自軍リーダーをペルセウスに変える。単独で敵地へ進軍し、敵の民を殺し家を（奪わず）焼き払う。指示に依存せず戦い続けるが、沼を踏めば他の民と同様に沈む。**基準となる英雄**で、他の英雄はこれとの差で定義される |
| トロイのヘレン | 中〜大 | 自軍リーダーをヘレンに変える。**戦闘に参加できない**——民を傷つけられない代わりに、**民には殺されない**（潰せるのは奇跡だけ）。最寄りの**敵の民または敵の家**へ向かい、民に触れれば魅了して拘束、**家に触れれば家を消し、中から出てきた者をその場で拘束する**（出てくる民はその家の人口ぶんの強さを持つ）。拘束された民は連れ回されるうちに**次第に力を失い、尽きると死ぬ**。拘束できる人数に上限は無い——上限の代わりに、この消耗が効果を区切る。**ヘレンが死ぬと拘束は解ける** |
| アドニス | 大 | 進軍の仕方はペルセウスと同じだが、**戦闘に勝つたびに2体へ分裂する**（それぞれ体力は半分）。分裂しすぎると弱い英雄が増え、英雄が死ぬたびにマナを失う |
| ヘラクレス | 大 | 進軍の仕方はペルセウスと同じだが、**戦闘力が2倍**で、**地割れに落ちない**。荒らされた地図を渡れる唯一の英雄 |
| オディッセウス | 中〜大 | 進軍の仕方はペルセウスと同じだが、**移動速度が1.8倍**。道の上ではさらに速い |
| アキレス | 大 | 進軍の仕方はペルセウスと同じだが、**火で焼死しない**。火の雨や延焼した森の中を歩ける |
| 火山 | 大 | 対象地点を高く隆起させ、火口から溶岩を流す。溶岩は低い方へ流れて広がるが、水地形で止まる。覆われた土地には建築できず、復旧には大量の地形操作が必要。**外周には水たまりが数か所でき、溶岩をそこで止める**（閉じた堀ではないので溶岩は隙間から出ていく）。**火柱が数本、火口の外側から外向きに立つ**（原作「火山の外周に水たまりができ、火柱が数本発生する」）——山と溶岩が固定の地形になった後も、火柱だけは動き続ける |
| 花 | 小 | 対象範囲の荒れた土地を元に戻す。地割れを埋め、火山の岩と溶岩を消し、火柱の焼け跡を戻し、沼を枯らす。**地震・火山・火柱・沼への対抗手段** |
| 森 | 小 | 対象地点の周囲に木を生やす。森の中の家は人口の増えが速い。ただし森はよく燃える |
| 竜巻 | 中 | 発動地点から一定時間さまよう。**通った先の家を吹き飛ばし**、巻き込んだ民を中心へ引きずりながら体力を削る。**海上を渡る間、一定間隔で渦巻きを産み続ける**（原作「海上では渦巻きを大量発生させるため、敵陣の海岸付近に大量に仕掛けると土地を広げにくくなるので効果的」）。竜巻自身は寿命が尽きるまで消えない |
| 渦巻き | 中 | **海上にしか撃てない。** 海上を移動しながら触れた陸地を海面まで削り、そこに居た民と家を沈める。一定時間ごとに分裂して被害範囲が広がる。**海上の竜巻からも生まれる**——直接撃つのは1つを狙った場所に置くこと、竜巻に産ませるのは撒くことである |
| 雷 | 中 | 指定地点の**周辺**へ複数の落雷。人は死に、家は焼け、地面は荒地になる。**狙った所ちょうどには落ちない**（散らばる）のがこの奇跡の性格。**押し続けると落ち続ける**（原作「雷はボタンを押し続けている間は落ち続ける」）——1回ごとにマナを取り、散らばりのおかげで狙い直さなくても一帯を掃ける |
| 嵐 | 大 | 指定地点に雷雲を留め、一定時間そこへ落雷し続ける。家を壊し地面を荒地にするが、**人には当たらない**。土地を使えなくする奇跡 |
| 火柱 | 中〜大 | 集結地から見て指定地点の向こうへ、さまよう火柱を立てる。触れた民は焼死し、家は崩れ、**通った地面は荒地になって建築できなくなる**（花で戻せる）。アキレスだけは焼死しない。**段差があると高い方へ寄っていく**ので、集落の下に置くと登ってくる。**足元の土地を海面まで下げると消える**——燃え出した火柱に対して打てる唯一の手である |
| ハリケーン | 中〜大 | 集結地から見て指定地点の向こうへ、細長い強風を一度だけ吹かせる。回廊内の家を壊し、民を風下へ吹き飛ばす。**それ自体では誰も殺さない**——飛ばした先に沼や亀裂があれば死ぬ |
| 火の雨 | 中 | 対象範囲に火を降らせ、民を殺し家を焼く。**森に落ちると森づたいに延焼し、範囲を遥かに超えて広がる** |
| 道 | 小 | 対象範囲を舗装する。上を歩く民の移動が速くなり、**毒カビはこれを越えられない**。毒カビの上には敷けない。**敵陣と斜面には敷けない**（原作「なお、敵陣や斜面には設置できない」）——舗装は平らな地面に置くものである |
| 城壁 | 小 | 対象地点に石壁の塊を築く。**民は越えられず、リーダーと英雄だけが越える**（原作「敵リーダー・ヒーロー以外の信者を遮る」）。一度の詠唱で築けるのは小さな塊なので、線にするには繋げて撃つ。水・亀裂・毒カビの上には築けず、**道と同じく敵陣と斜面にも築けない**。**築いた土地は上下できなくなる**（原作「城壁にかかる土地上下ができなくなる」）——遮るのが目的である以上、下から土地を抜けては意味が無い。**地震の地割れと火山の溶岩が壊す** |
| 地下巨石 | 中 | 対象地点の地面を大きく隆起させ、冷たい岩の塊を起こす。**建てられない上、周りの平地も壊すので大きな家が建たなくなる**。上に建っていた家は壊れるが、**人は死なない**。修復手段は無く、**海面まで掘り下げて沈めたときだけ消える**。**押し続けると一帯へ次々と巨石が起こる**（原作「発生ボタンを押し続けると、一帯により多くの巨石を発生させる」）——1回ごとにマナを払い、置ける場所が尽きるか指を離すまで続く |
| 毒カビ | 小 | 対象地点にカビを撒く。放置すると勝手に増殖し、届いた民と家を飲み込む。密集させるほど速く広がり、まばらなものは自然消滅する。**道で進行を止められる** |
| 岩礁 | 小 | 海上に岩を線分状に隆起させる。建築はできないが津波を砕く。1キャストでは波が回り込むので、海岸を塞ぐには何度か並べる |
| 津波 | 特大 | 発動地点から波が広がり、届いた低地を水没・侵食する。波の全高を超える地形と岩は波を止め、その背後を守る。海面自体は変わらない |
| 最終決戦 | 最大 | 両陣営の集結シンボルが世界の中央へ移動し、全ての民が家を捨てて中央に集まり、総力戦を行う。勝った陣営がゲームに勝利する。人口で明確に勝っているときの「決着ボタン」。**この行進だけはリーダーを介さない**——民は中央そのものへ向かう（通常の「集結シンボルへ」はリーダー追従） |

**英雄は自分と同じ系統の攻撃神技では死なない。** 原作の「※ヘラクレス除く」
「※アキレス除く」といった但し書きは個別の例外ではなく、1つの規則である
——「ただし、同じカテゴリーの攻撃神技は効果がない」。ヘラクレスは地割れに
落ちず（地）、アキレスは焼死せず（火）、オディッセウスには雷も竜巻も効かず
（気）、アドニスは沼にも毒カビにも沈まず（植物）、ヘレンは聖水の泉で
寝返らない（水）。守護者は game2 独自なのでペルセウスと同じ「人」に置く。
溺死は対象外——水の英雄が溺れないとはどの資料も書いていない。

**英雄が死ぬと、その陣営はマナを失う。** 英雄は投資であり、失えば代償がある
（アドニスを増やしすぎたときの歯止めでもある）。

## 9. 勝敗条件

- **勝利**：敵陣営の民と家をすべて消滅させる（または最終決戦で勝つ）。
- **敗北**：自陣営の民が全滅する。
- 引き分けはなく、決着までリアルタイムで争いが続く。

## 10. キャンペーン構造

- 固定ワールドを順に攻略していく**征服モード**が本編。
- **プレイヤーは「ゼウスと人間の女性の間に生まれた青年」。** 敵の16人の神に
  対して、プレイヤーが何者なのかが原作記事に明記されている。ワールド選択
  画面に一行で置く（そこが唯一16神を一覧できる画面であり、キャンペーンの
  入口でもある）。
- **SFC版は敵として16人の神が登場し、各3ステージ＝全48面。**
  原作記事はこの面数を賛否両論点として挙げている
  （「ステージ数が全48面と少ない。他機種版は数百面が当たり前」）。
  game2が再現の対象にしているのはSFC版なので、面数も48に合わせる。
  「約500ワールド」は初代『POPULOUS』や他機種版の数字であって、
  この48ではない。
- 神が対戦相手の単位で、同じ神と3戦する。神ごとに系統・気質・領土の
  地形が決まっており、難易度そのもの（敵AIの速さと攻撃性）は48面を
  通した1本の曲線として上がっていく。
- **面ごとに操作そのものが落とされることがある。** 原作は各面の開始前に
  10項目を○×で示す。game2 は**10項目すべて**を持つ——土地の↑／↓、
  敵陣での↑↓、底なし沼、**どこでも↑↓・海上に土地↑↓**（＝何もない海に
  土地を起こせるか。48面中5面だけ○で、残りは既にある陸地に接した所しか
  触れない）、**スプログ**（ゼウスの3面だけ×）、**溺れた人間の救出**
  （17面が×。マナ不要の操作で、溺れている自分の民を一番近い陸へ引き上げる）、
  そして**敵の位置表示**（11面が×＝世界儀に敵の点が出ない）と
  **災害箇所表示**（6面が×＝敵の奇跡が落ちた場所に印が出ない）。
  最後の2つは「できること」ではなく「分かること」を削る軸で、
  災害表示を落とす面は必ず敵位置も落としている。
- **48面は原作の表をそのまま使う**（`docs/original-maps.md`）。地上編
  （No.1〜30、ギリシアの地名）と天上編（No.31〜48、神々の宮）に分かれ、
  最後の相手はゼウスである。
- **使用可能な奇跡は面ごとに配り直される。累積ではない。** No.4 で
  ペルセウス・沼・火柱・雷が一斉に落ち、No.29 では前の面の14種が消える。
  同じ神の3面でも中身が違う。したがって単調に上がる軸は**敵AIの速さと
  攻撃性だけ**であり、キャンペーンを難しくしているのは手札ではなく相手
  である。
- 神の「系統」は世界選択に出る**その神の属性**であって、その面で撃てる
  という保証ではない。48面のうち6面は、その神の系統の奇跡を1つも許可して
  いない。敵AIは撃てないときは落とす（`enemyMiracles.ts`）——序盤の
  「土地上下とマグネットのみ」はそれで再現される。
- 地形タイプと敵の気質は原作の資料に記録が無いので **game2 の裁量**で
  割り当てている。
- **地形操作の制限も難易度の軸のひとつ。** 上下とも可 → 片方向のみ →
  上下不可、の順に厳しくなる。上下不可は最後の神（冥王ハデス）だけに
  置く。地形操作を取り上げる面は、奇跡が全て揃っていて初めて成立する
  （最終決戦を含む）ためである。
- クリアすると**パスワード（ワールド名）**が与えられ、そこから再開できる。
  勝ち方の内容（残存人口など）に応じて数ワールド先へスキップできる。
- 別途、設定をカスタムして1戦だけ遊ぶモードや、2人対戦モードを持つ。

### 敵AI

- **敵の神はワールドごとに系統（人・植物・地・気・火・水）を持つ。**
  その系統の代表的な奇跡を繰り返し撃ってくる——火の神は集落へ火の雨を、
  水の神は聖水の泉で民を奪う、という具合に。撃てるのはそのワールドが
  解禁している奇跡だけで、代表の奇跡が高いときは**貯まるまで待つ**
  （安い地震で埋め合わせない）。系統が解禁されていないワールドでは
  地震に落ちる。系統は世界選択画面に表示される。
- **敵は出撃前に軍を編成する。** 家を奪うには奪う側の強さが家の防御力を
  上回る必要があり（小屋3・中規模6・大きな家12・城砦20）、民は強さ1で
  生まれる。強さを足すには合流させるしかないので、敵は出撃条件を
  満たしても「相手の一番弱い家を奪える民」ができるまで集結を続け、
  できてから戦闘へ移る。攻め込まれているときは編成を待たずに応戦する。
  敵が使うのは集結であって合体ではない——旗に集めた方が編成の完了を
  判定しやすく、行軍の起点も決まるためで、合体を使わせない理由が
  あるわけではない。
- 敵の神はプレイヤーと同じルールで介入する。奇跡を撃てる範囲も同じで、
  自分の勢力と標的が1つの視界に収まるときにしか撃てない（8節「撃てる範囲」）。
  ワールドごとに
  「攻撃性」「賢さ」「介入速度」などのパラメータが設定され、難易度を形成する。
- 高難度では敵の介入頻度が上がるが、行動パターン自体は比較的予測可能。
- 上記は純粋な数値の難易度調整だが、それとは別に**気質**という軸を持つ。
  「好戦的」は少ない優勢でも火山・最終決戦に踏み切り、劣勢が明白な
  ときだけ守護者で守りを固める。「専守防衛」は逆に、優勢が固まる
  までなかなか踏み切らず、守護者に頼りがちになる。「堅実」は
  従来通りの基準値のまま。気質は難易度のように単調に厳しくなる軸
  ではなく、ワールドごとに「違う相手と対戦している」感覚を出すための
  ものであり、世界選択画面にも表示される。

## 11. UI 要素

- **メイン画面**：アイソメトリック表示の世界。クリックで地形操作。
- **世界儀（ミニマップ）**：世界全体の俯瞰。クリックで視点移動。
- **マナゲージ**：現在のマナ量と、解禁済み奇跡のアイコン列。
- **奇跡パネル**：原作と同じ6系統（人・植物・地・気・火・水）のタブで、
  **一度に1系統ぶん（最大5個）だけ**を表示する。29個を1つの格子に
  並べると探せなくなるため。系統を切り替えると選択中の奇跡は解除され
  照会へ戻る（見えていない奇跡が構えたままになるのを避ける）。
  隆起・沈降・平坦化は系統に入れず常時表示——このゲームの基本ループ
  そのものなので、1タップ余計にかかると割に合わない。
- **情報パネル**：任意のウォーカー・家を照会して人数／強さ／
  発達段階を確認できる。両陣営の総人口の比較表示もある。
- **スコアと評価**：試合中ずっと両陣営にスコアが入る。原作の言う4つの
  稼ぎ方——**地下巨石・岩礁を使う**／敵リーダーを倒す／直接戦闘に勝つ／
  時間が経つ——の順で価値が高い。試合終了時、プレイヤーのスコアは
  **稲妻マーク10個**を上限とする面の評価として「戦いの記録」の先頭に出る。
  マークを埋めたければ戦うより建てることになる、というのが原作の設計である。
- **奇跡のレベル**：面をクリアすると、その面で**実際に使った系統**へ稲妻
  マークの数だけ経験点が入り、6系統それぞれのレベル（1〜5）が上がる。
  レベル1は今までの game2 そのままで、上がると原作の言うとおりに効く——
  **雷は命中精度**（散らばりが縮む）、**地震・竜巻・嵐・火柱は持続時間**、
  **毒カビは激しさ**（種を広く撒くので細胞オートマトンが枯れずに広がる）。
  レベルは**パスワードで持ち運ぶ**（`ワールドID.経験点コード`）。昔の
  ワールドIDだけのパスワードも今までどおり通り、その場合はレベル1から。
- **世界儀（ミニマップ）**：両陣営の家と民を点で、敵の奇跡が落ちた場所を
  黄色い輪で示す。どちらも面ごとに落とされる（`enemyPositionsVisible` /
  `disasterMarkersVisible`）。輪は一定時間で消える——「今そこへ行け」と
  いう警告であって、試合の履歴ではない。
- **行動方針パネル**：定住／集結／シンボルへ／戦闘の切り替えアイコン。
- **救出**：スプログと並ぶマナ不要の操作。溺れている自分の民をタップして
  一番近い陸へ引き上げる。面ごとに封じられる（`rescueAllowed`）。

## 12. 実装に向けたデータモデルの素案

```
World
  ├ tiles[w][h]        … 頂点高さマップ (0=海面)
  ├ terrainType        … 草原/砂漠/雪原/溶岩 (成長係数)
  └ waterLevel         … 洪水で上昇する海面高さ

Faction (player / enemy)
  ├ mana               … 蓄積エネルギー
  ├ behaviorMode       … 定住/集結/シンボルへ/戦闘
  ├ shrinePosition     … 集結シンボルの座標
  └ leaderId           … リーダーのウォーカーID

Walker
  ├ faction, pos
  ├ strength           … 内部人数/戦闘力
  └ state              … 移動/定住/戦闘/騎士/守護者 など

House
  ├ faction, pos
  ├ level              … 小屋〜城砦
  └ population         … 蓄積人口 (満杯でウォーカー輩出、マナ供給量はレベル別
                          上限値にpopulation/capacityを掛けた分だけ発生)

Simulation (tick駆動)
  ├ ウォーカーAI (探索/建築/合流/戦闘)
  ├ 家の成長/人口生産
  ├ マナ蓄積
  └ 敵神AI (地形操作/奇跡の使用)
```
