# ゴッドゲーム システム調査資料

1980年代末に確立された「神視点リアルタイム戦略ゲーム（ゴッドゲーム）」の
ゲームシステムを調査し、本プロジェクトで再現するための仕様としてまとめる。

プレイヤーは神として世界に介入し、自分を信仰する民を間接的に導いて、
敵対する神の民と世界の覇権を争う。ユニットを直接操作することはできず、
「地形の操作」と「奇跡（パワー）」と「大まかな行動方針の指示」だけで
民を繁栄させ、敵勢力を殲滅することが目的となる。

---

## 1. ゲームの基本ループ

```
地形を平らに整える
      ↓
民が平地に家を建てる
      ↓
人口が増え、信仰エネルギー（マナ）が蓄積する
      ↓
マナを使ってさらに地形を整える／奇跡を起こす
      ↓
（繰り返し。最終的に敵勢力を全滅させる）
```

- ゲームは**リアルタイム**で進行する。敵AIも同時に同じ手段で介入してくる。
- 自陣営と敵陣営の2勢力。民は自動で行動し、直接命令はできない。

## 2. 世界（マップ）

- 見下ろし型の**アイソメトリック（クォータービュー）表示**。
- 地形は格子状で、**タイルの四隅（頂点）ごとに高さ**を持つ。
  高さ0が海面で、海には建物を建てられず、通常の民は入ると溺れる。
- 画面には世界の一部だけが表示され、スクロールで移動する。
  全体はミニマップ（世界儀）で俯瞰できる。
- **地形タイプ**が複数あり（草原、砂漠、雪原、岩・溶岩地帯など）、
  見た目だけでなく民の成長速度などに影響する
  （例：草原は標準、砂漠は成長が遅い、溶岩地帯はさらに過酷）。

## 3. 地形操作

- 最も基本の介入。**頂点を1段上げる／下げる**ことができ、少量のマナを消費する。
- 主目的は民のために**平地を作る**こと。平地が広いほど大きな建物が建つ。
- 逆に敵集落の周囲の地形を崩して妨害することもできる。
- 起伏の多い土地では小さく原始的な集落が多数でき（拡張は速いが弱い）、
  広い平地では大きく発達した集落になる（拡張は遅いが強固）、
  という戦略上のトレードオフがある。

## 4. 民（ウォーカー）

- マップ上を歩き回る自律ユニット。各ウォーカーは内部に「人数／強さ」を持ち、
  見た目は1人でも実際は集団を表す。
- 行動は自動：平地を探して**定住**し家を建てる、家が満杯になると
  新しいウォーカーが輩出される、など。
- 同勢力のウォーカー同士が出会うと**合流して1体の強いウォーカーになる**ことができる。
- 敵ウォーカーと接触すると**戦闘**になり、強さの高い方が勝ち残る。
- 敵の家に入ると戦闘の末、**家を奪う（自陣営化する）**か破壊する。
- 水に入ると溺れて死ぬ（後述のヒーロー（騎士・守護者）や、特殊な状況を除く）。
- 沼に入ると沈んで死ぬ。

### リーダー

- 自陣営のウォーカーのうち1体が**リーダー**となる（集結シンボルに最初に
  触れた者など）。リーダーは旗などで区別して表示される。
- 「集結」系の指示では民はリーダーの元へ向かい、リーダーは
  **集結シンボル**（後述）へ向かう。
- リーダーは奇跡「騎士化」「守護者化」の対象となる（ヒーローの種類は
  8節参照）。

## 5. 集落（家）

- ウォーカーが平地に定住すると**家**を建てる。
- 家は**周囲の平地の広さに応じて段階的に発達**する：
  小屋 → 中規模の家 → 大きな家 → 城砦（最大）。
  周囲の地形をさらに平らにすると自動でアップグレードされる。
- 家の周囲は**農地**になり、視覚的に勢力圏を示す。
- 家は時間とともに**人口を生産**し、満杯になると新しいウォーカーを外に出す。
  大きな家ほど生産が速く、マナ供給も多い。
- 地震などで周囲の地形が崩れると家はダウングレード／破壊される。

## 6. マナ（信仰エネルギー）

- プレイヤーの介入コストを支払う唯一の資源。ゲーム開始時は0。
- **信者の総人口に比例して自動蓄積**する。大きな集落（城砦）ほど供給が多い。
- 画面上に**マナゲージ**があり、ゲージ上に各奇跡のアイコンが並ぶ。
  - 左端＝最少コスト（地形の上げ下げ）、右端＝最大コスト（最終決戦）。
  - マナが各アイコンの閾値に達すると、その奇跡が**解禁**される。
  - 使用するとマナが減り、高位の奇跡は再び蓄積するまで使えない。
- 人口が多いほど蓄積が速い＝人口拡大がそのまま介入力の拡大につながる。

## 7. 行動方針の指示（影響）

民に与えられる大まかな行動モード。**マナ消費なし**で常にいずれか1つが
有効になっている。

| モード | 効果 |
|---|---|
| 定住 | 最寄りの平地へ向かい、家を建てて人口を増やす（標準の拡大方針） |
| 集結 | ウォーカー同士が合流し、少数の強いウォーカーにまとまる |
| 集結シンボルへ | 民はリーダーへ、リーダーはシンボルへ向かう（軍勢の誘導） |
| 戦闘 | 敵のウォーカー・家を積極的に探して攻撃する |

- 「集結してから定住」「戦闘してから定住」のような複合指示もある。
- **集結シンボル**は自陣営の信仰の対象となる像で、奇跡によって
  マップ上の任意の場所（自勢力の影響範囲）へ移動できる。
  敵地にシンボルを置き「シンボルへ」を指示することで侵攻を誘導する。

## 8. 奇跡（パワー）一覧

コストの低い順。効果と用途を示す。

| 奇跡 | コスト | 効果 |
|---|---|---|
| 地形上げ／下げ | 極小 | 頂点1つの高さを変更。序盤から常用する基本操作 |
| 集結シンボル移動 | 小 | シンボルを指定地点へ移動し、軍勢の目標地点を変える |
| 地震 | 中 | 対象範囲の地形をランダムに隆起・陥没させ、平地を壊す。敵集落のダウングレード・破壊に有効 |
| 沼 | 中 | 対象地点に沼を生成。踏み込んだ民は騎士・守護者を含め沈んで死ぬ。一定数を飲み込むと消えるタイプと恒久のタイプがある |
| 守護者化 | 中〜大 | 自軍リーダーを守護者に変える。守護者は自軍の集落の近くに脅威（敵ウォーカー・家）が現れたときだけ迎撃に向かい、奪った家は焼かず占領して生き延びる。脅威がなければ持ち場で待機する、専守防衛タイプのヒーロー。ただし沼には他の民と同様に沈む |
| 騎士化 | 大 | 自軍リーダーを騎士に変える。騎士は単独で敵地へ進軍し、敵の民を殺し家を（奪わず）焼き払う。指示に依存せず戦い続けるが、沼を踏めば他の民と同様に沈む |
| 火山 | 大 | 対象地点を高く隆起させ、岩石で覆う。岩の上には建築できないため敵の土地を長期的に奪う。復旧には大量の地形操作が必要 |
| 洪水 | 特大 | 海面を1段上昇させる。高さ1の土地がすべて水没し、低地の民・家は全滅する。使用側も被害を受けるため高台の確保が前提 |
| 最終決戦 | 最大 | 両陣営の集結シンボルが世界の中央へ移動し、全ての民が家を捨てて中央に集まり、総力戦を行う。勝った陣営がゲームに勝利する。人口で明確に勝っているときの「決着ボタン」 |

## 9. 勝敗条件

- **勝利**：敵陣営の民と家をすべて消滅させる（または最終決戦で勝つ）。
- **敗北**：自陣営の民が全滅する。
- 引き分けはなく、決着までリアルタイムで争いが続く。

## 10. キャンペーン構造

- 約500の固定ワールドを順に攻略していく**征服モード**が本編。
- 各ワールドは地形タイプ・初期配置・敵AIの攻撃性／賢さ・
  使用可能な奇跡の制限などが異なり、徐々に難しくなる。
- クリアすると**パスワード（ワールド名）**が与えられ、そこから再開できる。
  勝ち方の内容（残存人口など）に応じて数ワールド先へスキップできる。
- 別途、設定をカスタムして1戦だけ遊ぶモードや、2人対戦モードを持つ。

### 敵AI

- 敵の神はプレイヤーと同じルールで介入する。ワールドごとに
  「攻撃性」「賢さ」「介入速度」などのパラメータが設定され、難易度を形成する。
- 高難度では敵の介入頻度が上がるが、行動パターン自体は比較的予測可能。
- 上記は純粋な数値の難易度調整だが、それとは別に**気質**という軸を持つ。
  「好戦的」は少ない優勢でも火山・最終決戦に踏み切り、劣勢が明白な
  ときだけ守護者で守りを固める。「専守防衛」は逆に、優勢が固まる
  までなかなか踏み切らず、守護者に頼りがちになる。「堅実」は
  従来通りの基準値のまま。気質は難易度のように単調に厳しくなる軸
  ではなく、ワールドごとに「違う相手と対戦している」感覚を出すための
  ものであり、世界選択画面にも表示される。

## 11. UI 要素

- **メイン画面**：アイソメトリック表示の世界。クリックで地形操作。
- **世界儀（ミニマップ）**：世界全体の俯瞰。クリックで視点移動。
- **マナゲージ**：現在のマナ量と、解禁済み奇跡のアイコン列。
- **情報パネル**：任意のウォーカー・家を照会して人数／強さ／
  発達段階を確認できる。両陣営の総人口の比較表示もある。
- **行動方針パネル**：定住／集結／シンボルへ／戦闘の切り替えアイコン。

## 12. 実装に向けたデータモデルの素案

```
World
  ├ tiles[w][h]        … 頂点高さマップ (0=海面)
  ├ terrainType        … 草原/砂漠/雪原/溶岩 (成長係数)
  └ waterLevel         … 洪水で上昇する海面高さ

Faction (player / enemy)
  ├ mana               … 蓄積エネルギー
  ├ behaviorMode       … 定住/集結/シンボルへ/戦闘
  ├ shrinePosition     … 集結シンボルの座標
  └ leaderId           … リーダーのウォーカーID

Walker
  ├ faction, pos
  ├ strength           … 内部人数/戦闘力
  └ state              … 移動/定住/戦闘/騎士/守護者 など

House
  ├ faction, pos
  ├ level              … 小屋〜城砦
  └ population         … 蓄積人口 (満杯でウォーカー輩出、マナ供給量はレベル別
                          上限値にpopulation/capacityを掛けた分だけ発生)

Simulation (tick駆動)
  ├ ウォーカーAI (探索/建築/合流/戦闘)
  ├ 家の成長/人口生産
  ├ マナ蓄積
  └ 敵神AI (地形操作/奇跡の使用)
```
