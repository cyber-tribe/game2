# 原作（SFC版）の全48面データ

## 出典と信頼性

`https://achilleus.o-oku.jp/popu0.html` とその配下ページ（`popu1`＝操作と
進行、`popuk1`〜`popuk6`＝神技解説、`popum01`〜`popum16`＝マップ解説）。
同人誌からの再録を中心にした個人の攻略情報である。

**一次資料ではない。** 著者自身が神技解説を「全部記憶だけで書いたので一部
怪しいです」、マップ解説を「今回改めて検証はしてませんが」と断っている。
ゲームカタログ@Wikiの記事と食い違う箇所もある（後述）。したがって

- **面ごとの設定表（インフォメーション）と使用可能神技の表**は、画面の
  表示をそのまま写したものなので信頼度が高い。
- **神技の細かい挙動**は記憶に基づくので、カタログ記事と突き合わせて
  一致するものを採り、食い違うものは両論を残す。

を原則とする。
