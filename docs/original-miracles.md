# 原作『POPULOUS 2』の奇跡29個と相互作用

## この文書について

SFC版『POPULOUS 2』の奇跡の全体像をまとめた**参照用**の文書。
`docs/game-system.md` §8 が game2 の現在の奇跡一覧であるのに対し、
こちらは**再現の目標となる原作側の仕様**を記録する。

出典はプロジェクトオーナーの提供による。この開発環境からは原作の資料に
ネットワーク到達できず（`w.atwiki.jp` 等は `EGRESS_BLOCKED`）、
以前この情報が取れないことが実装のボトルネックになっていた。
以降の実装 PR はこの文書を参照する。

## 最も重要な前提

**『POPULOUS 2』は「攻撃奇跡を29種類持っているゲーム」ではない。**
土地・信者・建物・英雄・奇跡が互いに干渉するゲームであり、29という数は
その干渉の組み合わせがあって初めて意味を持つ。

奇跡を単体の効果として29個実装しても原作にはならない。**相互作用の節**を
実装計画の中心に置くこと。

## 6系統29個

奇跡は「人・植物・地・気・火・水」の6系統に分かれる。各系統に英雄化が
1つずつ含まれ、6英雄はそれぞれ異なる特性を持つ。

### 人 — 5個

| # | 奇跡 | 効果 |
|---|---|---|
| 1 | 土地上下 | 地形を上げ下げする。POPULOUSの基本操作 |
| 2 | マグネット移動 | 信者を集めるマグネットの位置を移動する。1人ずつ操作しない間接操作を支える |
| 3 | ペルセウス | リーダーを英雄ペルセウスへ。標準的な戦闘型で、敵地へ進んで攻撃する基準の英雄 |
| 4 | 病原菌 | 信者を感染させ周囲へ広げる。感染者はマナを供給できず、ハルマゲドンにも参加できない。即死ではなく国力を長期的に削る |
| 5 | ハルマゲドン | 最終決戦を強制。敵味方が住居を捨てて中央へ集まり、全滅まで戦う。開拓フェーズから殴り合いへ切り替える特殊な奇跡 |

### 植物 — 5個

| # | 奇跡 | 効果 |
|---|---|---|
| 6 | 森 | 周辺に木を生やす。信者の成長を促進する。**木は燃えやすい** |
| 7 | 花 | 荒れて建築不能になった土地を通常の平地へ戻す。沼・地割れ・火山で荒れた土地を修復。溶岩にも有効 |
| 8 | 沼 | 沼を作る。底なし沼なら入った信者は死亡。リーダーや英雄を狙う用途が強い。面ごとに底なしかどうか設定される |
| 9 | 毒カビ | 増殖する沼に近い。複数設置すると大繁殖し建物や信者を飲み込む。自然消滅することもある |
| 10 | アドニス | リーダーを英雄アドニスへ。**戦闘に勝つと2体に分裂**する（分裂後は体力が半分）。増やしすぎは英雄死亡時のマナ損失というリスクを伴う |

### 地 — 5個

| # | 奇跡 | 効果 |
|---|---|---|
| 11 | 道 | 道路を作る。上では信者の移動速度が上がる。**毒カビの進行を止める** |
| 12 | 城壁 | 信者の進行を遮る壁。英雄以外は越えられない（資料により「敵リーダー・英雄だけが越えられる」とも） |
| 13 | 地震 | 指定地点から**長い地割れ**を発生させる。落ちると死亡し、修復まで残る。**方向を持つ**破壊であって円形AoEではない |
| 14 | 地下巨石 | 発動地点を大きく隆起させ岩を発生。大規模建築の障害になり、海へ沈めるまで消えない |
| 15 | ヘラクレス | リーダーを英雄ヘラクレスへ。戦闘力が最も高い。**地割れに落ちない** |

### 気 — 5個

| # | 奇跡 | 効果 |
|---|---|---|
| 16 | 雷 | 指定地点周辺へ落雷。人は死亡、建物は燃焼、地面は荒地化。レベルが上がると威力ではなく**命中率**が向上する |
| 17 | 竜巻 | 一定時間ランダムに移動し被害を与える。信者を巻き込んで運び体力を減らす。**水地形へ入ると渦巻きへ変化する** |
| 18 | 嵐 | 雷雲を発生させ周辺へ継続的に落雷。単発の雷と違い範囲持続型。この雷は人には直接当たらない |
| 19 | オディッセウス | リーダーを英雄オディッセウスへ。**移動速度が速い**機動力特化 |
| 20 | ハリケーン | 指定方向へ強風。建物を壊し人を吹き飛ばす。**方向を持つ** |

### 火 — 4個

| # | 奇跡 | 効果 |
|---|---|---|
| 21 | 火柱 | 移動する火柱。ランダムに動き、地面を荒地化し人を焼死させ建物を崩壊させる。固定AoEではなく**移動する危険地帯** |
| 22 | 火の雨 | 一定範囲へ火を降らせる。火柱より即効性が高いが命中しないこともある |
| 23 | アキレス | リーダーを英雄アキレスへ。**火が効かず焼死しない** |
| 24 | 火山 | 発動地点を隆起させ火口から溶岩を流す。溶岩は建築不能地形を作り、**水地形で止まる**。水を埋め立てるとさらに外側へ流れ出す |

### 水 — 5個

| # | 奇跡 | 効果 |
|---|---|---|
| 25 | 岩礁 | 海底火山を噴火させ海上に岩礁を作る。建築はできないが**津波を防ぐ防波堤**になる。低コストでスコア効率が高い |
| 26 | 渦巻き | 海上を移動しながら陸地を削って水へ戻す。一定時間で分裂して被害範囲が広がる |
| 27 | 聖水の泉 | 落ちた信者が**敵側へ寝返る**。英雄まで寝返る可能性があり、強い英雄を奪えば形勢逆転できる。再度落ちると元へ戻る場合もある |
| 28 | トロイのヘレン | 女性英雄。**敵と戦わない**。敵信者を魅了・拘束して建物から引き離し連れ回す。ヘレンが死ぬと拘束は解ける。敵の人口・建築基盤を崩す |
| 29 | 津波 | 発動地点を中心に**全方向へ広がる**。低い土地を水没・侵食するが**高い土地は影響を受けない**。山や崖を防波堤にできる |

## 相互作用（ここが本体）

単体効果ではなくこの組み合わせこそが原作である。落としてはいけないもの:

| 組み合わせ | 内容 |
|---|---|
| 森 → 火の雨 | 森を作ってから火の雨で広範囲へ延焼させる |
| 道 → 毒カビ | 道が毒カビの拡散を止める。防疫としての地形制御 |
| 竜巻 → 渦巻き | 竜巻が水地形へ到達すると渦巻きへ変化する。属性をまたぐ連鎖 |
| ハリケーン → 沼／地割れ | 吹き飛ばす先に沼や亀裂を用意して即死地形へ押し込む |
| 岩礁 → 津波 | 岩礁が津波を食い止める防波堤になる |
| 花 → 荒地 | 沼・地割れ・火山・溶岩で荒れた土地を修復する |
| 聖水 → 英雄 | 敵の英雄を寝返らせて奪う |
| 火山 → 水 | 溶岩は水地形で止まる。水を埋め立てると外へ流れ出す |
| 高地 → 津波 | 高い土地は津波の影響を受けない。地形が防御になる |

実装済みの相互作用: 森→火の雨、岩礁→津波、道→毒カビ、地割れ→ヘラクレス、
火→アキレス、道→オディッセウス。
花（地震の亀裂・火山の岩・沼の修復）は別PRで進行中。

game2 独自のものとして「平坦化」と「守護者化」があるが、どちらも原作には
ない。守護者は専守防衛型の英雄で、原作の6英雄はいずれも守りに就かない。

### 洪水の性質が違う（解消済み）

かつての game2 の `applyFlood` は `heightmap.waterLevel` を1つ上げる
**全世界一律の海面上昇**で、「使用側も等しく被害を受ける全体災害」だった。
原作の津波が持つ、局所性・高地による防御・岩礁による防御はいずれも
`applyTsunami` と `applyReef` で入っている。`applyFlood` 自体は
ハルマゲドン等の全体災害として残っている。

## 実装の順序について

29個を一度に入れることはしない。`CLAUDE.md` の方針通り、意味のある単位ごとに
PRを分ける。順序の考え方:

1. **既にあるが性質が違うもの**を原作に寄せる（津波、地震の方向性、火山の溶岩）。
   数を増やすより、既存の奇跡が原作の挙動になる方が「原作らしさ」への寄与が大きい。
2. **相互作用の土台になるもの**（森、道、岩礁、花）。これらは単体では地味だが、
   相互作用の片側を担うため先に要る。
3. **六英雄**。騎士／守護者を置き換える形になり、既存のヒーロー機構を触るので
   まとまった単位になる。うち固有特性が「既にある奇跡への免疫・強化」で済む
   4人（ペルセウス・ヘラクレス・オディッセウス・アキレス）は実装済み。残る
   アドニス（戦闘勝利で分裂）とトロイのヘレン（敵信者を魅了して連れ回す）は
   どちらも新しい仕組みが要るので別扱いとする。
4. **残りの攻撃奇跡**。

各段階で、対応する相互作用を同じPRに含める。相互作用こそが目的であり、
奇跡の数は手段に過ぎない。
