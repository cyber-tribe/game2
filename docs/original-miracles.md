# 原作『POPULOUS 2』の奇跡29個と相互作用

## この文書について

参照する資料は2つある。**ゲームカタログ@Wikiの記事**（
`https://w.atwiki.jp/gcmatome/pages/3538.html`）と、**個人の攻略情報
サイト**（`https://achilleus.o-oku.jp/popu0.html` 一式）。後者から取った
面ごとのデータは `docs/original-maps.md` にある。どちらも二次資料なので、
差分を足すときは**どちらのどの一文が根拠か**を併記する。


SFC版『POPULOUS 2』の奇跡の全体像をまとめた**参照用**の文書。
`docs/game-system.md` §8 が game2 の現在の奇跡一覧であるのに対し、
こちらは**再現の目標となる原作側の仕様**を記録する。

当初の出典はプロジェクトオーナーの提供によるもので、この開発環境からは
原作の資料にネットワーク到達できないものとされていた。

その後、原作記事（`w.atwiki.jp/gcmatome/pages/3538.html`）を実際に取得
できることが分かった。到達できなかった原因は先方のブロックではなく
開発環境側にあり、ヘッドレスChromiumのTLS 1.3 ClientHelloをプロキシが
拒否していたためである（`--ssl-version-max=tls1.2`で解決する）。

したがってこの文書は、**一次資料と突き合わせて更新できる**。オーナー提供の
要約と原作記事で食い違う箇所や、要約になかった記述が見つかった場合は、
原作記事側を正としてこの文書を直し、差分を実装へ反映する。
以降の実装 PR はこの文書を参照する。

## 最も重要な前提

**『POPULOUS 2』は「攻撃奇跡を29種類持っているゲーム」ではない。**
土地・信者・建物・英雄・奇跡が互いに干渉するゲームであり、29という数は
その干渉の組み合わせがあって初めて意味を持つ。

奇跡を単体の効果として29個実装しても原作にはならない。**相互作用の節**を
実装計画の中心に置くこと。

## 6系統29個

奇跡は「人・植物・地・気・火・水」の6系統に分かれる。各系統に英雄化が
1つずつ含まれ、6英雄はそれぞれ異なる特性を持つ。

### 人 — 5個

| # | 奇跡 | 効果 |
|---|---|---|
| 1 | 土地上下 | 地形を上げ下げする。POPULOUSの基本操作 |
| 2 | マグネット移動 | 信者を集めるマグネットの位置を移動する。1人ずつ操作しない間接操作を支える |
| 3 | ペルセウス | リーダーを英雄ペルセウスへ。標準的な戦闘型で、敵地へ進んで攻撃する基準の英雄 |
| 4 | 病原菌 | 信者を感染させ周囲へ広げる。感染者はマナを供給できず、ハルマゲドンにも参加できない。即死ではなく国力を長期的に削る |
| 5 | ハルマゲドン | 最終決戦を強制。敵味方が住居を捨てて中央へ集まり、全滅まで戦う。開拓フェーズから殴り合いへ切り替える特殊な奇跡 |

### 植物 — 5個

| # | 奇跡 | 効果 |
|---|---|---|
| 6 | 森 | 周辺に木を生やす。信者の成長を促進する。**木は燃えやすい** |
| 7 | 花 | 荒れて建築不能になった土地を通常の平地へ戻す。沼・地割れ・火山で荒れた土地を修復。溶岩にも有効 |
| 8 | 沼 | 沼を作る。底なし沼なら入った信者は死亡。リーダーや英雄を狙う用途が強い。面ごとに底なしかどうか設定される |
| 9 | 毒カビ | 増殖する沼に近い。複数設置すると大繁殖し建物や信者を飲み込む。自然消滅することもある |
| 10 | アドニス | リーダーを英雄アドニスへ。**戦闘に勝つと2体に分裂**する（分裂後は体力が半分）。増やしすぎは英雄死亡時のマナ損失というリスクを伴う |

### 地 — 5個

| # | 奇跡 | 効果 |
|---|---|---|
| 11 | 道 | 道路を作る。上では信者の移動速度が上がる。**毒カビの進行を止める** |
| 12 | 城壁 | 信者の進行を遮る壁。**「敵リーダー・ヒーロー以外の信者を遮る」**——リーダーと英雄の2種類だけが越えられる（原作記事の記述。当初の要約は「英雄以外は越えられない」としつつ、この読みも併記していた） |
| 13 | 地震 | 指定地点から**長い地割れ**を発生させる。落ちると死亡し、修復まで残る。**方向を持つ**破壊であって円形AoEではない |
| 14 | 地下巨石 | 発動地点を大きく隆起させ岩を発生。大規模建築の障害になり、海へ沈めるまで消えない。**発生ボタンを押し続けると一帯により多くの巨石を発生させる** |
| 15 | ヘラクレス | リーダーを英雄ヘラクレスへ。戦闘力が最も高い。**地割れに落ちない** |

### 気 — 5個

| # | 奇跡 | 効果 |
|---|---|---|
| 16 | 雷 | 指定地点周辺へ落雷。人は死亡、建物は燃焼、地面は荒地化。レベルが上がると威力ではなく**命中率**が向上する |
| 17 | 竜巻 | 一定時間ランダムに移動し、**建物を吹き飛ばし**、信者を巻き込んで運び体力を減らす。**海上では渦巻きを大量発生させる**（いずれも原作記事。当初の要約は建物への被害に触れず、「渦巻きへ変化する」＝1体になる、としていた） |
| 18 | 嵐 | 雷雲を発生させ周辺へ継続的に落雷。単発の雷と違い範囲持続型。この雷は人には直接当たらない |
| 19 | オディッセウス | リーダーを英雄オディッセウスへ。**移動速度が速い**機動力特化 |
| 20 | ハリケーン | 指定方向へ強風。建物を壊し人を吹き飛ばす。**方向を持つ** |

### 火 — 4個

| # | 奇跡 | 効果 |
|---|---|---|
| 21 | 火柱 | 移動する火柱。ランダムに動き、地面を荒地化し人を焼死させ建物を崩壊させる。固定AoEではなく**移動する危険地帯** |
| 22 | 火の雨 | 一定範囲へ火を降らせる。火柱より即効性が高いが命中しないこともある |
| 23 | アキレス | リーダーを英雄アキレスへ。**火が効かず焼死しない** |
| 24 | 火山 | 発動地点を隆起させ火口から溶岩を流す。溶岩は建築不能地形を作り、**水地形で止まる**。水を埋め立てるとさらに外側へ流れ出す |

### 水 — 5個

| # | 奇跡 | 効果 |
|---|---|---|
| 25 | 岩礁 | 海底火山を噴火させ海上に岩礁を**線分状に**作る。建築はできないが**津波を防ぐ防波堤**になる。低コストでスコア効率が高い |
| 26 | 渦巻き | 海上を移動しながら陸地を削って水へ戻す。一定時間で分裂して被害範囲が広がる |
| 27 | 聖水の泉 | 落ちた信者が**敵側へ寝返る**。英雄まで寝返る可能性があり、強い英雄を奪えば形勢逆転できる。再度落ちると元へ戻る場合もある |
| 28 | トロイのヘレン | 女性英雄。**戦闘することができず、神業でしか潰せない**。最寄りの敵信者または敵建物へ向かい、信者は魅了して拘束、**建物は自ら消して中から出てきた者を拘束する**。拘束された者は連れ回されるうちに力尽きて死ぬ。敵の人口・建築基盤を崩す |
| 29 | 津波 | 発動地点を中心に**全方向へ広がる**。低い土地を水没・侵食するが**高い土地は影響を受けない**。山や崖を防波堤にできる |

## 相互作用（ここが本体）

単体効果ではなくこの組み合わせこそが原作である。落としてはいけないもの:

| 組み合わせ | 内容 |
|---|---|
| 森 → 火の雨 | 森を作ってから火の雨で広範囲へ延焼させる |
| 道 → 毒カビ | 道が毒カビの拡散を止める。防疫としての地形制御 |
| 竜巻 → 渦巻き | 海上を渡る竜巻が渦巻きを次々と産む。属性をまたぐ連鎖 |
| ハリケーン → 沼／地割れ | 吹き飛ばす先に沼や亀裂を用意して即死地形へ押し込む |
| 岩礁 → 津波 | 岩礁が津波を食い止める防波堤になる |
| 花 → 荒地 | 沼・地割れ・火山・溶岩で荒れた土地を修復する |
| 聖水 → 英雄 | 敵の英雄を寝返らせて奪う |
| 火山 → 水 | 溶岩は水地形で止まる。水を埋め立てると外へ流れ出す |
| 高地 → 津波 | 高い土地は津波の影響を受けない。地形が防御になる |

実装済みの相互作用: 森→火の雨、岩礁→津波、道→毒カビ、地割れ→ヘラクレス、
火→アキレス、道→オディッセウス、聖水→英雄寝返り、竜巻→渦巻き、
ハリケーン→沼／亀裂、高地→津波（波は全高を超える地形で止まる）、
火山→水（溶岩は水地形で止まり、埋め立てれば外へ流れ出す）、
花→荒地（沼・亀裂・火山の岩と溶岩・焼け跡の修復）。

**原作29個は全て実装済みである。**

城壁とともに、ウォーカーが障害物を迂回する仕組み（`systems/movement.ts`
の `stepAroundWalls`）が入った。経路探索ではなく局所的な操舵で、壁に
当たったら片側へ回り込み、まっすぐ進めるようになったら回り込みをやめる。
三方を囲まれた袋小路からは出られないが、それは壁にできてよいことだと
判断した。城壁→地震（地割れが壁を断ち切る）、城壁→火山（溶岩が壁を
埋める）が新しい相互作用である。

地下巨石は「通行」ではなく「建築」を妨げる。原作の「大規模建築の障害に
なり」の通り、岩そのものが覆う頂点だけでなく、隆起が作る斜面が周囲の
平地を壊すので、覆っていない場所の大きな家も建たなくなる（平地40x40で
計測: 覆う頂点29に対し城が建たなくなる頂点37）。地下巨石→沈降（海面まで
掘り下げると消える）、地下巨石→火山（溶岩が呑むと溶岩岩に変わる）が
新しい相互作用である。

火柱→花（焼け跡の修復）、アキレス→火柱（火柱でも焼死しない）、
雷→アキレス（火は効かないが落雷では死ぬ）も実装済み。花（地震の亀裂・
火山の岩・溶岩・火柱の焼け跡・沼の修復）も完了している。

game2 独自のものとして「平坦化」と「守護者化」があるが、どちらも原作には
ない。守護者は専守防衛型の英雄で、原作の6英雄はいずれも守りに就かない。
どちらも原作にあるものを置き換えてはいない（原作の自動整地は平坦化とは
別に入っており、原作の英雄6人は6人とも居る）ので、選択肢として残している。

## 攻略情報サイトから追加で分かったこと

出典は `https://achilleus.o-oku.jp/popu0.html` 一式。信頼度の扱いは
`docs/original-maps.md` の冒頭に書いた——面ごとの設定表は画面の写しなので
高く、神技の細部は著者自身が「記憶で書いた」と断っているので中くらいである。

### 保留が解けた —— 奇跡のレベル

「レベルが上がると威力ではなく命中率が向上する」という要約の一行だけを
根拠にするのは早い、として保留していたが、この資料が**カテゴリー別の
レベル体系**を繰り返し裏付けた。

- 「各マップごとにスコアに応じて**経験点**が入り、**各カテゴリーの
  レベル**を上げていくことができる」
- 雷：「気レベルが低い段階では**命中精度が非常に低く**使い物にならないが、
  レベルが上がる（50〜100程度）と一撃必殺の破壊力がある」
- 地震・竜巻・嵐・火柱：効果の**持続時間**がそれぞれのレベルで伸びる
- 毒カビ：「植物のレベルが高いと一瞬かなりえげつないことになる」
- 経験点の稼ぎ方（効果の高い順）：**地下巨石・岩礁を使う**／敵リーダーを
  倒す／ウォーカー同士の直接戦闘に勝つ／時間が経つ
- 面の評価は**稲妻マーク10個**（約5万点）が上限

要約の言う「命中率」は雷のことだった。差分として確定、**未実装**である。

### 直した —— ヘレンの挙動を取り違えていた（`plan/0144`で修正済み）

game2 は「魅了された民が自陣の建物を壊す」と実装した（`plan/0133`）。
カタログ記事の「敵信者を魅了して**建物を更地にさせ**」をそう読んだが、
この資料はヘレン自身の動作として具体的に書いている。

> 敵ウォーカーと接触したところで**竪琴を一閃すると戦うことなく相手を
> 拘束**出来る。また、**敵建物に接触して竪琴を一閃すると建物が消滅し、
> 現れたウォーカーを拘束する**。

建物を消すのは**ヘレン自身**で、更地になった建物から出てきた者がそのまま
拘束される。拘束された者は「歩き回っているうちに次第にパワーが減少し、
力尽きると死ぬ」。ヘレンが先に死ねば拘束は解ける（ここは一致）。拘束
人数の上限には触れていない。

`plan/0144-helen-razes-buildings-herself.md` で直した。上限
（`HELEN_CHARM_CAPACITY`）は消し、代わりに拘束した者の消耗
（`HELEN_CAPTIVE_DRAIN_RATE`）で効果を区切っている——資料が言うのは
「かなり多く拘束できる」であって「4人まで」ではない。

### 原作記事との突き合わせは一巡した

「概要」「システム」「全奇跡の簡単な説明」「神の啓示」「評価点」
「賛否両論点」「問題点」を1行ずつ実装と照合し、見つかった差分は上の表に
入れて全て塞いだ。以降この文書に差分を足すときは、**記事のどの一文が
根拠か**を併記すること。要約だけを根拠にした行が、この一巡で見つかった
食い違いの大半だった（岩礁の形、城壁を越える者、竜巻の被害、ヘレンの

## 実装の順序について

29個を一度に入れることはしない。`CLAUDE.md` の方針通り、意味のある単位ごとに
PRを分ける。順序の考え方:

1. **既にあるが性質が違うもの**を原作に寄せる（津波、地震の方向性、火山の溶岩）。
   数を増やすより、既存の奇跡が原作の挙動になる方が「原作らしさ」への寄与が大きい。
2. **相互作用の土台になるもの**（森、道、岩礁、花）。これらは単体では地味だが、
   相互作用の片側を担うため先に要る。
3. **六英雄** —— 完了。固有特性が「既にある奇跡への免疫・強化」で済む4人
   （ペルセウス・ヘラクレス・オディッセウス・アキレス）をまとめて入れたあと、
   新しい仕組みを要求するアドニス（戦闘勝利で分裂＋英雄死亡時のマナ損失）と
   トロイのヘレン（戦わず敵の民を拘束して連れ回す）を1人ずつ入れた。
4. **残りの攻撃奇跡** —— 完了。
5. **一次資料との突き合わせ** —— 上の「原作記事と突き合わせて直したもの」。
   奇跡が29個揃ったあとに残っていた差分は、数ではなく**性質**の側に
   あった。形（岩礁の線分）、操作（押し続け・自動整地・スプログ）、
   例外（城壁を越えるのは誰か）、面の設定（底なし沼）、そして
   キャンペーンの規模である。

各段階で、対応する相互作用を同じPRに含める。相互作用こそが目的であり、
奇跡の数は手段に過ぎない。
