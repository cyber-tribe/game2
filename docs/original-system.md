# 原作『POPULOUS 2』のシステム（奇跡以外）

## この文書について

SFC版『POPULOUS 2』のうち、**奇跡そのもの以外**の仕様——ステージ構成・
神の啓示・マナ経済・人口の上限・操作方法——を記録した**参照用**の文書。

奇跡29個とその相互作用は`docs/original-miracles.md`にある。本文書は
その姉妹編で、`docs/game-system.md`（game2 の現仕様）に対する
**再現目標となる原作側の仕様**という位置づけも同じ。

出典はプロジェクトオーナーの提供による（原典は
`https://w.atwiki.jp/gcmatome/pages/3538.html`）。この開発環境からは
原作の資料にネットワーク到達できない（`w.atwiki.jp` は
`EGRESS_BLOCKED`。プロキシは `w.atwiki.jp:443` への CONNECT に 403 を返す）
ため、原作側の記述は**この文書に書かれている範囲がすべて**であり、
実装時にコード側から原典を引き直すことはできない。ここに無い細部は
オーナーに確認すること。推測で埋めない。

## 1. ステージ構成

- **敵の神は16人。1人につき3ステージで、合計48面。**
- game2 の現在の6ワールド（`src/game/worlds.ts` の `WORLDS`）とは
  規模も構造も別物である。
- 「ワールドごとに敵神が1つの系統（`enemySchool`）を持ち、その系統の
  代表奇跡を撃つ」という現在の設計は、原作仕様として本資料には
  記載がない。**game2 独自**である。

## 2. 神の啓示は4種類

原作の啓示は**集合・合体・戦闘・定住**の4つ。

| 啓示 | 効果 |
|---|---|
| 集合 | 信者を集める |
| 合体 | 近くの信者同士が合体して力を増す。**近くに相手がいなければ定住と同じ挙動になる** |
| 戦闘 | 敵を攻撃する |
| 定住 | 家を建てて人口を増やす |

「合体」は独立した1つの啓示であり、「集合」とは別物である。
合体相手がいないときに定住へフォールバックする性質は、原作の側の仕様。

## 3. マナ経済

- **信者数と時間経過に応じてマナが蓄積する。**
- つまり原作では**人口そのものが神力の源泉**であり、家の種類や軒数を
  介さない。

## 4. 人口の上限

- 原作に「一陣営あたり何軒まで」といった固定上限があるという記述は**ない**。
- むしろ原典では、**信者が増えすぎてフィールドを埋め尽くし、処理落ちや
  オーバーフローを起こせてしまうこと**が問題点として挙げられている。
  上限がないどころか、上限の無さが欠点として語られている。
- 勢力差は、平地の量・人口・破壊によって**自然に**生まれる設計。

## 5. 操作

### スプログ（B）

- 建物の中心にカーソルを合わせて **B** を押すと、**満員になる前でも
  信者の一部を外へ追い出せる**。
- 原典では、これによって前作より進行が速くなったと**評価点**として
  明記されている。単なる時短ではなく、「いつ人口を外へ放出するか」を
  プレイヤーが能動的に決められることがゲームテンポの核になっている。
- 対象は**カーソル下の1軒**である。

### 自動整地（X）

- **X** ボタンで、**カーソル下の建物を中心とした7×7マスを自動的に平地化**する。
- 範囲は建物中心の固定7×7であり、任意範囲を塗る方式ではない。

### 地下巨石の連続生成

- 地下巨石は**ボタンを押し続けると一帯にさらに多くの巨石を出せる**。
  1回の発動で1つ、ではない。

## 6. 奇跡一覧に関わる原作側の事実

`docs/original-miracles.md` の29個の一覧に対する補足。

- **渦巻きは、プレイヤーが直接発動できる奇跡として一覧に存在する。**
  海面上を移動して土地を削り、分裂する。竜巻から派生するだけの現象では
  ない（竜巻由来の発生と両立する）。
- **原作の英雄は6人**——ペルセウス・アドニス・ヘラクレス・オディッセウス・
  アキレス・ヘレン。**「守護者（guardian）」は原作に存在しない。**
