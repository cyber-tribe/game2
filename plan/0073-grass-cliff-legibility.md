# 芝生と断面（崖）の視認性改善

## 背景

ユーザーから「芝生とその断面の表現がいけてない、視認性が悪い」との
指摘。続けて「前に見せた原作のデザインも確認して、ライティングと影の
問題もありそうですね」との追加フィードバックがあり、セッションに
アップロード済みの原作（Populous系タイトル）のスクリーンショットを
改めて確認した上で対応した。

## 診断

`src/render/IsoRenderer.ts`を調査し、2つの独立した問題を特定:

1. **芝生のディザーパターンが荒く見える**: `createDitherTexture`が
   8x8ピクセルのタイル状ディザーテクスチャを作る際、各ピクセルの
   色決定に`tileHash(x, y) = frac(sin(x*127.1+y*311.7)*43758.5453)`
   （ボルケーノのひび割れ角度用に作られた既存のハッシュ関数）を
   流用していた。このハッシュは連続的な広い範囲の入力に対しては
   良いばらつきを示すが、8x8のごく小さい整数格子でサンプリングすると
   周期的なエイリアシングを起こし、ランダムな斑点ではなく数個の
   大きな三角形ブロックが繰り返されるパターンになっていた
   （実機スクリーンショットで確認済み）。
2. **崖の断面がほぼ見えない**: `drawCliffWalls`は崖の壁を
   「上面の色を35%黒に近づけただけ」の単色で塗っていた。芝生の
   場合、上面の基準色`TERRAIN_COLOR.grass`（0x4a8c3f）を35%暗くすると
   (48, 91, 41)になるが、これは芝生ディザーの暗い斑点色
   `GRASS_SPECKLE_COLOR`（0x336228 = (51, 98, 40)）とほぼ同一色。
   つまり暗い斑点の真下に崖があると、色差がほぼゼロで境界が
   全く見えなかった。これが「視認性が悪い」の直接的な原因。

さらに、原作のスクリーンショットを詳細に確認したところ
（`/root/.claude/uploads/`内の該当画像を参照）、同じ台地の2つの
可視な崖面が明確に異なる明るさで塗られている——一方はオレンジ寄りの
明るい茶色、もう一方（プレイヤーに近い前面）はより暗いマルーン系の
茶色。これは固定された光源方向に基づくディレクショナルシェーディング
であり、このレンダラーには一切実装されていなかった
（4方向の壁が常に同じ1色）。これがユーザーの言う
「ライティングと影の問題」。

## 対応

`src/render/IsoRenderer.ts`:

1. **ディザーハッシュの差し替え**: `createDitherTexture`専用の
   `ditherPixelHash`を新設（整数の乗算+xorシフトによる
   "hash32shift"系のビット混合ハッシュ）。小さな整数格子でも
   周期性を持たず、細かい斑点として見えるようになった。
   `tileHash`自体はボルケーノのひび割れ用途では問題ないため
   変更していない。
2. **芝生の崖に専用の土色を導入**: `GRASS_CLIFF_COLOR`
   （0x8a6a45、アーシーな茶色）を新設。芝生地形の崖だけは
   この色を基準に暗くし、それ以外の地形（砂漠・雪原・岩盤）は
   従来通り自身の上面色を暗くする。色相そのものを変えることで、
   芝生ディザーのどのピクセルの真下でも確実にコントラストが
   出るようにした。原作や多くの地形ベース建設ゲームが
   「上は緑、断面は土色」という配色をしているのに倣った。
3. **崖壁のディレクショナルシェーディング**: `drawCliffWalls`が
   4方向すべてに同じ`CLIFF_SHADE_AMOUNT`（35%減光）を使っていたのを
   やめ、光源を北東方向（`toScreen`の -y/+x 方向）に固定した
   2階調シェーディングに変更。北・東向きの壁は光源側を向くため
   明るい`CLIFF_LIT_SHADE_AMOUNT`（15%減光）、南・西向きの壁は
   `CLIFF_SHADE_AMOUNT`（35%減光、従来通り）とした。原作の
   スクリーンショットで確認した「同じ台地の2つの壁面が異なる
   明るさ」を再現している。

## 検証

- `npm run typecheck`: エラーなし
- `npm run test -- --run`: 410件全て成功。
  `IsoRenderer.test.ts`に以下を追加/更新:
  - 崖壁が上面より暗いことを検証する既存テストを、方向によって
    2階調になったことを反映して更新（3色 = 上面 + 明/暗の壁2色）。
  - 芝生の崖が緑ではなく土色（赤≧緑>青のチャンネル関係）で
    塗られることを検証するテストを更新（2階調分）。
  - 台地の北・東の壁が南・西の壁より明るいことを、
    `drawCliffWalls`の`.poly([topA.sx, topA.sy, ...])`の
    最初の頂点座標から幾何学的に各壁の方向を特定して検証する
    新規テストを追加。
- `npm run build`: 成功。
- Playwright（chromium）による実機確認: 最初の（草原）ワールドで
  地形をなぞって隆起させ、ズームインしたスクリーンショットを撮影。
  以前は完全にのっぺりした一色に見えていた地形の起伏が、
  ディザー修正だけで既にはっきり見えるようになり、さらに
  ディレクショナルシェーディングにより同じ台地の隣接する2つの
  崖面が異なる明るさで塗り分けられ、原作の見た目に近い立体感が
  得られたことを確認した。
