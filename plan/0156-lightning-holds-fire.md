# 0156 lightning-holds-fire

## 原作「雷はボタンを押し続けている間は落ち続ける」

game2 の雷は1タップ1斉射だった。撃ち続けたければタップし続けるしかなく、
これは操作の問題であると同時に**性格の問題**である。原作の雷は
「レベルが低いと命中精度が非常に低い」奇跡であり、外れるからこそ押し続け
られるようになっている。1発ずつしか撃てない散弾は、ただの当たらない奇跡
である。

## 地下巨石と同じ仕掛けを使う

game2 には既にこの形がある——地下巨石の「押し続けると一帯に増える」
（`plan/0119` の `megalithHolding`）。長押しで発動し、一定間隔で撃ち直し、
指が動けば止まる。雷はそこに乗る。

そこで `megalithHolding` / `megalithHoldTimer` / `stopMegalithHold` を
`holdCasting` / `holdCastTimer` / `stopHoldCast` に改名した。押し続けで
繰り返す奇跡が2つになった以上、片方の名前で共有の状態を持つのは嘘になる。

**狙い直さない。** 地下巨石の長押しは `megalithScatterCandidates` で次の
置き場所を選び直すが、雷は毎回同じ点を狙う。1回の斉射がすでに
`LIGHTNING_SCATTER` の円へ散るので、同じ点を撃ち続けるだけで一帯を掃ける
——散らばりが「命中精度」の正体である以上、それを外から補ってはいけない。

**間隔は 800ms**（巨石は 500ms）。値段はほぼ同じ（20 と 24）だが、斉射は
5発が即死で、巨石は地面を起こすだけである。500ms だと指が「長押しした」と
気付く前に集落が消える。800ms なら1斉射の結果を見てから離せる。

## 検証

- `npm run typecheck` / `npm run build` パス、テスト886件パス（+3）。
- 「狙い直さなくてよい」という判断そのものを検証する3件——同じ点への
  2回目が1回目と違う所に落ちること、8斉射すべてが散らばりの内側に
  留まること（長押しが的から逸れていかない）、1斉射では残る人垣が
  繰り返しで掃けること。
- 長押しの配線そのものは `main.ts`（DOM側）にあり、巨石の長押しと同じく
  ユニットテストの対象外である。テストできる部分を関数に切り出す方針も
  同じ（`castLightningAt`）。
