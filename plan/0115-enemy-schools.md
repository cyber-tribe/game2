# 敵の神に系統を持たせる

## 発端

プレイヤーは29個の奇跡を持つのに、**敵が撃つのは地震・火山・英雄化・
最終決戦の4種だけ**だった。`docs/game-system.md` には「敵の神は
プレイヤーと同じルールで介入する」と書いてあるのに、道具立てが
まるで違っていた。

## 系統で分ける

奇跡パネルを原作の6系統に分けた（plan/archived/0113）ばかりだったので、
同じ分類を敵神にも使う。**ワールドごとに敵神が1系統を持ち、その系統の
代表的な奇跡を繰り返し撃つ。**

| ワールド | 系統 | 代表の奇跡 |
|---|---|---|
| 静かな草原 | 地 | 地震 |
| 乾いた高地 | 植物 | 沼 |
| 凍てつく国境 | 気 | 雷 |
| 灰の荒野 | 火 | 火の雨 |
| 隆起する辺境 | 人 | 病原菌 |
| 最終戦線 | 水 | 聖水の泉 |

系統ごとに1つだけなのは意図的である。敵はタイマーで、固定の優先順位で、
届く集落へ撃つ。5個から自由に選ばせると「性格」ではなく「ランダム」に
見える。**繰り返される1つの署名**だからプレイヤーは学習して備えられる
——docs/game-system.md の「行動パターン自体は比較的予測可能」。

代表の奇跡は「相手の集落に何をするか」で選んだ。人＝病原菌（殺さずに
マナを止める）、植物＝沼（歩いている先に穴）、地＝地震、気＝雷、
火＝火の雨（森づたいに燃える）、水＝聖水の泉（**殺さずに民を奪う**）。

## 安い地震で埋め合わせない

最初の実装では、代表の奇跡が高くて買えないときに地震へ落ちるように
した。計測すると、

```
隆起する辺境 人  {地震: 184, 病原菌: 87}
最終戦線     水  {地震: 169, 聖水の泉: 86}
```

**聖水の泉1つにつき地震2つ撃つ神は水の神ではない。** 貯まるまで待って、
その回は何もしないようにした。

```
隆起する辺境 人  {病原菌: 34, 火山: 2, 守護者: 5}
最終戦線     水  {聖水の泉: 145, 守護者: 1}
```

（4試行×480秒、両陣営とも無操作。病原菌が34まで減るのは、同じ集落が
まだ感染中だと2度目が何もしないため——`seedPlague` が0を返す回は
マナを使わない。感染が切れるのを待つ神になっている）

系統が解禁されていないワールドでは地震に落ちる。**プレイヤーと同じ
`allowedMiracles` に従う**ので、これは避けられないし避けるべきでもない。

## ワールドごとに1つずつ解禁を足した

系統を名乗る以上その奇跡が撃てないと嘘になるので、
凍てつく国境に**雷**、灰の荒野に**火の雨**、隆起する辺境に**病原菌**を
解禁した。累積の規則は保っている（後のワールドは前のを全部含む）。
**プレイヤー側も同じだけ早く使えるようになる**——これは副作用として
記録しておく。

## 分類はどこに置いたか

`src/game/miracleSchools.ts` へ移した（UIから game/ へ）。パネルの
タブと敵神の系統が**同じ表**を読む必要があるからで、世界選択で「火」と
名乗る神が沼を撃つのは、プレイヤーから見える嘘になる。
`ui/miracleCategories.ts` は ToolMode への橋として残っている。

## 検証

- 688 → 698テスト。`miracleSchools`（全奇跡がちょうど1系統に入る／各系統の
  個数が原作の表と一致／各系統に英雄1人／**全系統に代表の奇跡があり、
  それがその系統に属する**／**全ワールドで代表の奇跡が解禁されている**／
  6系統すべてがキャンペーンに登場する）、`enemyMiracles`（自分の系統の
  奇跡を撃つ／**買えないときは貯めて地震に落ちない**／系統が未解禁なら
  地震／**効果が無い病原菌ではマナを使わない**）
- typecheck / build / `sprites:check` / `palette:check` 通過
- 世界選択に「敵の系統: 火」を常時表示（気質と違い、全ワールドに必ずある）
- 本番ビルドで実機確認。世界選択に6ワールドぶんの系統が正しく出た
  （地／植物／気／火／人／水）。静かな草原（地）を150秒放置すると
  **「敵が地震を起こした」だけ**が出る。灰の荒野（火）を放置すると
  **「敵が火の雨を降らせた」**が出る。コンソールエラーなし

## 貧しい神は沈黙する

実機で灰の荒野を**150秒**見たときは敵が一度も撃たなかった。330秒では
撃った。岩地形はマナが貯まるのが遅く、そこへ「安い地震に落ちない」を
足したので、**序盤の貧しい神は無言になる**。これは「安い地震で埋め
合わせない」判断の裏側であって、隠さずに書いておく。

`plan/0114`（敵が経済を作る前に出撃するのをやめさせる、PR #121）が
入れば敵は先に建てるので、この沈黙は短くなるはずである。両方が入った
状態での再計測は、そちらがマージされてからにする。
