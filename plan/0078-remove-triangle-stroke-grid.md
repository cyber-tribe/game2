# 地形三角形の黒フチが作る格子模様を除去

## 背景

ユーザーから実機（スマートフォン）のスクリーンショットとともに
「これじゃ視認性が悪すぎます。原作に可能な限り揃えてください。
同じだと最高です」との指摘。添付画像では、平坦な芝生の上一面に、
斜めの細い線が作るダイヤモンド格子模様がはっきり見えており、
本来なめらかに見えるはずの地形が全体的にちらついた金網のように
見えてしまっていた。

## 診断

`plan/0073`〜`0077`（`grass-cliff-legibility`ブランチ、既にマージ済み）
で地形を頂点ごとの傾斜メッシュ（タイルあたり2枚の三角形）に作り直した
際、`IsoRenderer.ts`の`fillTerrainTriangle`と水タイルの四角形の両方に
`.stroke({ width: 1, color: 0x000000, alpha: 0.15 })`が残っていた。
これは旧来の「タイル=1つの四角形」時代からの名残で、当時はタイルの
境界を示す程度の効果しかなかったが、今は1タイルが2枚の三角形に
分割されているため、**同じ色の隣接する三角形同士の間にも**この黒い
フチが描かれてしまう。平坦な地面が大半を占めるマップでは、この
「意味のない継ぎ目線」が画面全体を覆うダイヤモンド格子として
はっきり見えてしまい、原作画像で見られるような「同じ色は継ぎ目なく
一枚に見える」表現から大きく外れていた。

デスクトップ（PixiJS chromium、antialias off, 等倍）での確認では
比較的目立たなかったが、実機（高DPIのスマートフォン画面）では
くっきりと格子として見えてしまうことが、ユーザーの指摘するスクリー
ンショットで確認できた。

## 対応

`src/render/IsoRenderer.ts`:

- `fillTerrainTriangle`から`.stroke(...)`を削除。
- 水タイルの四角形フィルからも同様に`.stroke(...)`を削除。

原作の参考画像でも、ファセット同士の境界線は「実際に明るさが変わる
場所（＝本物の傾斜や崖）」にしか現れず、同じ色の面同士に黒い輪郭線を
引くことはない。ストロークを完全に削除したことで、フチ無しの
`fillTerrainTriangle`同士の色が一致する限り継ぎ目なく溶け合い、
実際に傾斜・崖がある場所だけ色の変化そのもので境界が見えるという、
原作に近い見た目になった。

## 検証

- `npm run typecheck` / `npm run test -- --run`（411件、
  `IsoRenderer.test.ts`のストローク関連アサーションを更新）/
  `npm run build`: すべて成功。
- Playwright（chromium、iPhone 13のdevice設定でdevicePixelRatioも
  再現）で実機に近い条件で確認: ユーザーのスクリーンショットで
  見えていたダイヤモンド格子模様が完全に消え、平坦な地面が継ぎ目
  なく一枚に見えるようになったことを確認。傾斜・崖のシェーディング
  自体は引き続き機能しており（色の変化で境界が分かる）、コンソール
  エラーも無かった。
