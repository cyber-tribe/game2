# 0107 開始直後の全滅を塞ぐ

## 症状

ハリケーン（plan/archived/0103）と火柱（plan/archived/0106）の実機確認で、
**開始40秒前後に1発撃っただけで試合が終わった**。2つの奇跡で2回起きたので
偶然ではない。放置しても90秒は終わらないので、勝手に決着する不具合ではない。

## 原因（推測ではなく計測）

ヘッドレスで `Simulation` を回し、各陣営の**広がり**と「半径1.2の円1つが
何割を巻き込めるか」を測った。最終ワールドと同じ岩地形・同じ敵AI設定:

```
t= 1s enemy: walkers=3 houses=0 spread=0.0 worst-circle=3/3
t=20s enemy: walkers=3 houses=0 spread=0.0 worst-circle=3/3
t=40s enemy: walkers=0 houses=3 spread=0.0 worst-circle=3/3
```

**spread=0.0。** 40秒経っても陣営全体が1点に乗っている。原因は2つ:

1. **開始ウォーカーが全員まったく同じ座標に湧いていた。** そして遊んでいる
   ウォーカーを動かすものは何もない
2. **家を建てる場所に間隔の規則が無かった。** 同じ点に立った3人が同じ点に
   3軒建てる

つまり奇跡が強すぎたのではなく、**陣営が1点に収まっていた**。半径がある
ものなら何でも一撃で全滅させられる状態で、たまたま新しい2つで踏んだだけで
ある。重なった家は描画でも重なって見えず、それぞれ満額のマナを稼ぐ。

## 手当

- `INITIAL_WALKER_SPREAD = 1.5`。開始ウォーカーを集結地の周りに**環状に**
  配置する。乱数ではなく決定的にしたのは、誰にも見えない形で開幕が変動する
  のは良くないから。そもそも「集結地に集まっている」はこの形だったはず
- `HOUSE_SPACING = 1`。既にある家の上には建てない。断られたウォーカーは
  `seeking` のまま残り、後のtickで別の場所へ歩く（何も詰まらない）。同じ
  tickで2人が同じ場所に建てないよう、その場で建った家も判定に加える

奇跡側の数字（`FIRE_PILLAR_LIFETIME`・`HURRICANE_LENGTH`）は**触っていない**。
原因が奇跡ではなかったので。

## 効果（同じ計測）

```
        変更前                          変更後
t=40s   spread=0.0  worst-circle=3/3    spread=12.7 worst-circle=1/5   (player)
t=90s   spread=14.6 worst-circle=5/22   spread=17.5 worst-circle=3/47  (player)
```

実機でも、**火柱とハリケーンの両方**を開幕に撃って12秒後に試合が続いている
ことを確認した（どちらも変更前は即決着していた）。

## 残る話

最終ワールドの敵は岩地形（成長倍率0.4）と好戦的AIのせいで40秒時点でも家が
1〜数軒しかなく、**そもそも陣営が小さい**。1点集中は解消したが、
「敵の経済が harsh terrain で伸びない」のは別の問題として残る。こちらは
奇跡ではなく敵AIと地形倍率の話なので、手を付けるなら独立して測るべき。
