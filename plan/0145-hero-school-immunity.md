# 0145 hero-school-immunity

## 規則がひとつあった

攻略資料は神技ごとに但し書きを置いている。

> 沼「※アドニス除く」／地割れ「※ヘラクレス除く」／雷「※オディッセウス除く」
> ／竜巻「※オディッセウス除く」／火柱「※アキレス除く」／火の雨「※アキレス
> 除く」／火山の溶岩「※アキレス以外」／聖水の泉「※トロイのヘレン除く」

**この8個は全て、その神技が属する系統の英雄である。** そして資料は
ヒーローの項でその規則そのものを書いている。

> ※ただし、**同じカテゴリーの攻撃神技は効果がない**。

game2 はこのうち2つを**名指しのif文**として持っていた
（`crevice.ts` の `state === "hercules"`、`fire.ts` の `=== "achilles"`）。
残りは無かった。2つの特例に見えていたものが、規則の2例だったことになる。

## 実装

`miracleSchools.ts` に `HERO_SCHOOL`（英雄→系統）と
`resistsSchool(state, school)` を置き、各所を差し替えた。

| 神技 | 系統 | 効かない英雄 | 以前 |
|---|---|---|---|
| 沼 | 植物 | アドニス | 全員沈む |
| 毒カビ | 植物 | アドニス | 全員沈む |
| 地割れ | 地 | ヘラクレス | 名指しのif |
| 雷 | 気 | オディッセウス | 全員死ぬ |
| 竜巻 | 気 | オディッセウス | 全員巻き込む |
| 火柱 | 火 | アキレス | 名指しのif |
| 火の雨・延焼 | 火 | アキレス | 名指しのif |
| 火山の溶岩 | 火 | アキレス | 全員埋まる |
| 聖水の泉 | 水 | ヘレン | 全員寝返る |

`isHeroState` を型ガード（`state is HeroKind`）にした。`HERO_SCHOOL` を
`HeroKind` で引くのに必要で、ついでに他所のキャストも要らなくなる。

### 溺死は含めない

津波・洪水・渦巻きの侵食で海に沈む経路はこの規則を見ない。資料のどこにも
「水の英雄は溺れない」とは書いていない。規則は**攻撃神技が英雄を倒せるか**
の話であって、地面が無くなることの話ではない。

### 守護者の置き場所

game2 独自の守護者は「人」——ペルセウスと同じ系統に置いた。奇跡の側でも
守護者化はペルセウスと並べてある（`MIRACLE_SCHOOL`）ので、そこと揃う。

## 検証

- `npm run typecheck` / `npm run build` パス、テスト820件パス（+13）。
- `miracleSchools.test.ts` に規則そのもののテストを4件——資料が名指しした
  8つの例外を1行ずつ／他系統には効かない／普通の民は何も防がない／
  原作の6英雄が6系統を1つずつ占める。**一覧ではなく規則を確かめている。**
- 各神技側にも実地のテストを足した（沼・毒カビ・雷・竜巻・聖水の泉・火山）。
  どれも「その英雄は無事」と「他の英雄はやられる」を対で置いている。
