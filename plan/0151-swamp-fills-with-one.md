# 0151 swamp-fills-with-one

## 資料

> インフォメーションの「底無し沼」が○の場合は修復されるまで有効だが、
> ×の場合は**1人が落ちると埋まって普通の地面に戻る**。

game2 は `SWAMP_CAPACITY = 5` だった。

## 1と5では別の神技になる

5人だと、埋まる沼と底なし沼は「程度の違い」でしかない。1人なら**別物**に
なる。埋まる方は1人ぶんの罠であり、集落へ撒くものではなく、歩いてくる
リーダーの足元に置くものである。

原作の側の助言もそこから出ている。「底無し沼×の場合はある程度埋めたら
完全に埋めるよりも他の作業に移った方が良い」——1人で埋まるからこそ、敵に
撒かれた沼は放っておいても勝手に消費されていく。

なお原作48面のうち底なしでないのは**5面だけ**である
（`docs/original-maps.md`）。これは稀な方の設定にあたる。

## 差分表の4件目の誤り

同じPRで直そうとしていた「毒カビを建物に重ねて置くと建物を潰す」は、
**もともと実装されていた**。`fungus.ts` の家の走査は成長間隔ではなく毎tick
で走るので、家の下に撒いた毒カビは次のtickでその家を消す。

`plan/0148` で3件見つけて訂正したが、まだ残っていた。表の「要」は着手する
たびに実物を確かめてから直す。

## 検証

- `npm run typecheck` / `npm run build` パス、テスト853件パス（+2）。
- 「1人で埋まり、2人目は地面の上を歩く」「底なしなら2人とも沈み沼も残る」。
- 既存テストを1件直した。`plan/0145` で足した「アドニス以外の英雄は沈む」が
  同じ沼に2人を立たせていたので、底なし沼に変えた——あれは**誰が沈むか**の
  テストであって、埋まる沼が何人取るかのテストではない。
