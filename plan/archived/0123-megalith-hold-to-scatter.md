# 0123 megalith-hold-to-scatter

## 背景

原作記事の地下巨石の説明には、game2 が拾えていなかった一文がある。

> 地下巨石：大きな建物を作るのに障害となる巨石を発生させる。
> **発生ボタンを押し続けると、一帯により多くの巨石を発生させる。**

game2 の地下巨石は1タップ＝1個で、押し続けても何も起きなかった。
`docs/original-miracles.md` の要約にもこの一文は無く、原作記事を取得して
初めて分かった差分である。

これは単なる操作の便利さではない。地下巨石は「大規模建築の障害」であり、
1個では敵の城が1軒建たなくなるだけだが、一帯に散らばれば**その一帯が
まるごと大きな家を建てられない土地になる**。押し続けられるかどうかで、
この奇跡が担える役割の規模が変わる。

## アプローチ

### 押し続けの解釈

原作は「一帯により多くの巨石」と書いている。同じ1点に積み上げるのでは
なく、周辺へ散る。押し続けたまま指が動かなくても散らばるのが要点で、
ここが既存の「ブラシ」（`plan/archived/0054-terraform-brush.md`）と違う。ブラシは
ポインタが**新しいタイルへ移った**ときに1回編集する仕組みなので、指を
止めたままでは何も起きない。

そこで地下巨石は専用の扱いにした。

- 長押し（`LONG_PRESS_DURATION_MS`）で発動を開始する。ブラシと同じ閾値
  なので、素早いタップやパンの開始と取り違えない。
- 1個目は**押した頂点そのもの**へ置く。タップした場合と同じ位置であり、
  押し続けはそのキャストを置き換えるのではなく積み増す。
- 以後 `MEGALITH_HOLD_INTERVAL_MS`（500ms）ごとに、`MEGALITH_SCATTER_RADIUS`
  （6頂点）以内の**まだ巨石を置ける頂点**から1つ選んで置く。
- 指を離す、`DRAG_THRESHOLD` を超えて動かす、マナが尽きる、一帯が
  埋まりきる、のいずれかで止まる。

間隔を500msとブラシよりかなり遅くしたのは、ブラシがポインタの移動速度に
律速されるのに対しこちらは指を止めたまま繰り返すためで、1回ごとに
`MEGALITH_MANA_COST`（24）を払う。「押し続けて石の原野を作る」が
「気づく前にマナを空にする」にならないための間隔である。

### 置ける頂点の判定

`megalithScatterCandidates` を `heightmap.ts` に置いた。`applyMegalith` が
頂点ごとに見ているのと同じ条件（マップ内・既に巨石でない・亀裂でない・
水面より上）で候補を返す純粋関数である。

空の配列が返ることが「一帯が埋まりきった」の合図になり、押し続けが
自分で止まれる。これが無いと、何も起こさないキャストにマナだけ払い続ける。

### 離したときに二重キャストしない

`pointerup` は「ドラッグでもブラシでもない」ときに `applyTool` を呼ぶ。
押し続けが成立していたらここでもう1回撃たれてしまうので、条件に
`!megalithHolding` を足した。

## 検証

`megalithScatterCandidates` のテストを追加。

- 候補が `MEGALITH_SCATTER_RADIUS` 以内に収まり、かつ
  `DEFAULT_MEGALITH_RADIUS`（石1個の footprint）より外にも及ぶこと
  ——「一帯」が石1個ぶんより広いこと
- 既に巨石がある頂点を返さないこと
- 水と亀裂を返さないこと（`applyMegalith` が何も起こせない場所）
- 一帯が埋まりきったら空配列になること（押し続けが止まれること）
- マップ端でもマップ内に収まること

`npm run typecheck` / `npm run test`（741件）/ `npm run build` すべてパス。
