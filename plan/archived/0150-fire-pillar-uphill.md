# 0150 fire-pillar-uphill

## 資料

> 移動方向はランダムだが、**段差があると高い方へ動きやすい傾向**がある。
> Ｌ＋Ｂ(3×3土地下げ)等で**水中に落とすと消火できる**。

game2 の火柱は一様な乱歩で、消す手段が無かった（寿命を待つだけ）。

## 直したもの

### 高い方へ寄る

`uphillDirection` が周囲4タイルの標高から勾配を取り、単位ベクトルにして
進行方向へ `FIRE_PILLAR_UPHILL_BIAS` の重みで足す。

**傾きであって規則ではない。** 実際にどこへ行くかは相変わらず乱歩が決め、
平地では寄与が完全にゼロになる。変わるのは、斜面に置いた火柱がどちらへ
流れやすいか——集落が建っている高い方へ登っていくか、海へ転げ落ちるか
である。これで「集落の下に置く」という狙い方が成立する。

### 足元を沈めると消える

一歩進んだ後の位置が海面以下なら消える。

### この2つは繋がっている

テストを書いていて気づいた。**前方に水路を掘っても消えない**——高い方へ
寄る性質が、低い水路から遠ざける方向に働くからである。消すには足元の
地面を下げるしかない。

これは資料の言い方と一致する。「水中に**落とす**」であって「水路に誘い込む」
ではない。L+B が3×3の土地下げであることまで含めて、**火柱の真下を抜く**
操作を指している。2つの規則が噛み合って、消火が「その場で払う代償のある
一手」になる。

## 検証

- `npm run typecheck` / `npm run build` パス、テスト851件パス（+4）。
- 下り方向に向けた火柱が斜面に引き戻される／平地では一切曲がらない／
  足元を3×3で沈めると消える／乾いた地面の上では消えない。
