# 奇跡パネルを原作の6系統に分ける

## 発端

29個が揃った結果、パネルは**同じ形のボタン26個が1つの格子に並ぶ壁**に
なっていた。花を探すには26個を全部読むしかない。

以前にも「メニューボタンが増えすぎて操作するマップ画面が小さいです」と
いう指摘を受けている（index.html のコメントに残っている）。あのときより
ボタンは10個増えている。

## 原作はそう並べていない

`docs/original-miracles.md` の通り、原作の奇跡は
**「人・植物・地・気・火・水」の6系統**に分かれ、各系統に英雄が1人ずつ
いる。game2 の29個はそのままこの6系統へ収まる。

- 人: 集結地移動・ペルセウス・病原菌・最終決戦（＋game2独自の守護者化）
- 植物: 森・花・沼・毒カビ・アドニス
- 地: 道・城壁・地震・地下巨石・ヘラクレス
- 気: 雷・竜巻・嵐・オディッセウス・ハリケーン
- 火: 火柱・火の雨・アキレス・火山
- 水: 岩礁・聖水の泉・トロイのヘレン・津波（渦巻きは竜巻からしか生まれ
  ないのでボタンが無い）

**1系統ずつ、最大5個だけ**を表示する。系統ごとに英雄が1人ずつ入るのが
原作の作りで、これを保っているからこそ「6個の袋に5個ずつ」ではなく
意味のある分類になっている。

## 隆起・沈降・平坦化は系統に入れない

原作では土地上下は人系統の#1だが、これはこのゲームの**基本ループ**
そのものである。「平地を作る」は他のあらゆる判断の合間に挟まる操作で、
そこへ1タップ増やすのはパネルを片付けるために最も頻繁な操作へ税を
かけることになる。照会と一緒に常時表示のままにした。

## 系統を切り替えたら構えを解く

気で竜巻を選び、火を見に行き、そのまま地図をタップすると**22マナが
忘れていた奇跡に消える**。選択中の奇跡だけがパネルから見えなくなる
状態を作ってしまうので、系統を切り替えたら照会（無害・無料）へ戻す。

## 計測

同じ画面上で、新しいパネルと「26個を1つの格子に戻したもの」の高さを
測った。

| | パネルの高さ |
|---|---|
| 26個を1格子（従来） | 331px |
| 6系統タブ（本PR） | **203px** |

**128px** ぶん地図が広がる（900px の画面で約14%）。ただし主目的は面積では
なく、**探すものが26個から5個になる**ことである。

## 検証

- 669 → 676テスト。系統の割り当て（重複なし／常時表示ツールは含まない／
  各系統の個数が原作の表と一致／**各系統に英雄が1人**／順序）に加えて、
  **index.html の実際のマークアップ**を `?raw` で読み、TypeScript側の
  分類と一致するか（系統ごとのボタンの並び／初期表示は人だけ／常時表示
  ツールが系統に混ざっていない）を検査する。手書きHTMLと分類表が黙って
  ずれるのを止めるため
- typecheck / build / `sprites:check` / `palette:check` 通過
- 本番ビルドで実機確認。6系統すべてを切り替えて中身が一致すること、
  アイコン欠けが無いこと、津波を構えてから系統を切り替えると解除され
  照会へ戻ることを確認。コンソールエラーなし

## 実装中に踏んだ罠

`.command-row { display: grid }` は詳細度が同じで後から来るため、
ブラウザ既定の `[hidden] { display: none }` に**勝ってしまう**。
そのため最初の実機確認では、しまったはずの5系統が全部描かれたまま
高さ486pxになっていた。`.command-row[hidden] { display: none }` を
明示して解決した。
