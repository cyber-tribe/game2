# 0152 original-campaign

## キャンペーンを発明するのをやめた

`docs/original-maps.md` に原作の48面の表が全部ある。game2 の `WORLDS` は
それを使わず、**16神を発明して奇跡を累積で配っていた**——神の1面目で
何かが解禁され、その神の3戦は同じ手札で、以後決して減らない。

原作はそんなことをしていない。No.4 でペルセウス・沼・火柱・雷が一斉に
落ち、No.29 では前の面の14種が消える。同じ神の3面でも中身が違う。

表を素直に読む以外に、これを再現する方法は無い。

## 入れたもの

`STAGES` という48行の表にした（`docs/original-maps.md` から機械生成し、
手で写していない）。1行が1面で、

- **地名・神・章**（地上編 No.1〜30／天上編 No.31〜48、最後はゼウス）
- **使用可能神技**（面ごと）
- **土地の↑／↓** → `terrainEditRule`
- **敵陣での↑↓** → `enemyTerritoryEditable`
- **底なし沼** → `bottomlessSwamp`

`GODS` は表から**導出**するようにした。キャンペーンは面の並びであり、
「神」とはそれを共有する連続3面のことである。

残る7項目（どこでも↑↓／海上に土地↑↓／溺れた人間の救出／敵の位置表示／
スプログ／災害箇所表示）は game2 に受け皿が無いので、別のPRにする。

### game2 の裁量として残したもの

- **地形タイプと敵の気質。** 原作の資料に記録が無い。16の土地に変化を
  付けるために割り当てた（地上編は緑寄り、天上編は神々の宮らしく）。
- **敵AIの速さと攻撃性。** 48面を通した単調な曲線。**今やこれだけが
  単調に上がる軸である**——原作の手札は増えたり減ったりするので、
  キャンペーンを難しくしているのは相手であって道具ではない。
- **守護者化**はペルセウスと同じ面に配る。game2 独自の英雄なので原作の
  表に行が無く、対になる基準の英雄に付けるのが自然である。

## テストで前提が変わったところ

7件落ちた。**どれも旧モデルの不変条件を書いたものだった**ので、原作の表で
実際に成り立つ主張へ置き換えた。

| 旧 | 新 |
|---|---|
| 神の3面は手札まで同じ | 相手（系統・気質・地形）は同じ、**手札は違ってよい**／実際に違う面がある |
| 神の系統の奇跡は必ず解禁済み | 系統は6つのどれかで3面共通。**撃てるかは面次第**（6面は自分の系統が1つも無い）／どの系統も撃てる面が最低1つある |
| 奇跡は各1回だけ解禁される | **どこかの面で必ず配られる** |
| 手札は決して減らない | **減る面が実在する** |
| 最終面で全奇跡が揃う | 最終面は空でも全部でもない（原作の最終面には集結地移動が無い） |
| 敵陣編集は一度falseなら戻らない | **戻る**（月神の宮は ○→×→○）。両方向に使われていることを見る |
| 土地上下不可は最後で全奇跡が揃う | **土地を奪える奇跡が配られている**（渦巻き・津波・火山のどれか） |

置き換えは緩めたのではなく、**別のことを主張している**。旧テストは
「累積で解禁する」という設計の検算であって、原作の性質ではなかった。
