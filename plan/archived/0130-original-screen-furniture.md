# 0130 original-screen-furniture

## 背景

原作の実機スクリーンショット5枚（`plan/archived/0129-world-edge-strata.md` 参照）から
読み取れた画面構成の差分のうち、そこでは「プラットフォームの問題」として
記録するに留めた2件を実装する。オーナーの判断は次の通り。

> 左上の浮遊世界地図 → 採用
> 右上の円形劇場型勢力表示 → 採用
> 下部石板UI → 採用する方針だが第二段階

理由も明確に示された。**game2の機能はPOPULOUSに近いのに、画面を見た瞬間には
POPULOUSに見えない**。左上と右上に構造物が入ると、そこが「神が世界を俯瞰して
いる画面」になる。

## 注文

試作段階のものに対して、はっきりした注文があった。

> 右上の「13本の柱列」は原作の円形劇場というより、岩盤の上に棒グラフを
> 置いたものにまだ見える。原作の魅力は「棒グラフを柱っぽくした」ことでは
> なく、**円形劇場という世界内オブジェクトそのものが勢力ゲージになっている**
> ことである。

これが本PRの設計方針そのものである。**ゲージを建物に見せるのではなく、
建物を作った結果ゲージが出てくる**ようにする。

## 円形劇場（`src/render/PopulationGauge.ts`）

建築として組み立て、勢力表示はその一部として出てくる形にした。

- **床は楕円**。真円を斜め上から見たものであり、これによって世界と同じ
  投影に乗る。試作の直線柱列にはこれが無く、だから棒グラフに見えていた。
- **客席は床を囲む輪**を扇形に割ったもの。これがゲージで、2色の境目が
  すり鉢を横切って動く。試作では奥半分だけを塗っていたため手前が空石のまま
  残り、建物の半分が使われていなかった。輪全体にしたことで、境目が
  「両神の前線が劇場を横切って動く」ように読める。
- **列柱は外周に立ち、奥から手前の順に描く**（`columnDepthOrder`）。
  端の柱が奥の柱の前に重なる。この重なりが、立体であることを伝える
  いちばん安い手がかりである。索引順に描くと同じ柱がそのまま棒グラフに
  戻ってしまう。
- **基壇の岩**が全体を載せ、下へ房が垂れて虚空へ落ちる。世界の切り口
  （`EDGE_STRATA`）や世界地図の岩盤と同じ材質に見えるようにしてある。

扇形は16。偶数なので互角の試合がちょうど半分に割れる（奇数だと中央の
1枚をどちらかへ寄せる必要がある）。分解能は約6%で、「今どちらが優勢か」を
一目で見るには十分細かく、数値そのものよりはるかに粗い——一瞬で読む物に
対して正しい取引だと判断した。

## 世界地図の岩盤（`src/render/Minimap.ts`）

こちらにも同じ注文が効く。石の枠を付けるだけでは額縁である。

- **上面・胴体・房**の3部構成にした。世界の切り口と同じ構造で、同じ物質に
  見せる。
- 上面の輪郭を**欠けさせた**。きれいな長方形は、何色で塗っても額縁に
  見える。角が割れていることが「どこかから引き剥がされた地面に地図が
  嵌っている」と言う。
- 位置を右上から**左上**へ移した。

## 下部パネルからバーを1本外した

人口比較が右上へ移ったので、下部の2色バーは削除した。同じことを2箇所で
言う必要はない。残ったマナは、勢力の傾きではなく純粋な量なので、
棒のままで正しい。

## 判断が要る点として挙げ、その上で採った トレードオフ

- **分解能**：16扇形＝約6%刻み。バーより粗いが、上記の通り一目で読む物に
  対しては十分。
- **ミニマップが左上**：右利きの親指から遠い。ただしミニマップは奇跡ボタン
  ほど頻繁に触るものではなく、原作の画面構成を崩してまで右上に残す利点は
  小さい、という判断。

## 未着手（第二段階）

下部パネルの遠近石板化・雷文の縁取りは手を付けていない。方針としては採用。

## 検証

`src/render/PopulationGauge.test.ts` を追加。

- 互角の試合で境目がちょうど中央に来ること、両極で全部が片側に行くこと、
  範囲外の入力が丸められること
- **プレイヤーが左から埋まる**こと（置き換えたバーと同じ向き）。これは
  コード上は見えず、画面では一目で分かる種類の間違いである
- どの位置の扇形も必ずどちらかに属すること
- 列柱が**奥から手前の順**に描かれること、全部の柱がちょうど1回ずつ出る
  こと、近い柱が遠い柱より先に描かれないこと

`npm run typecheck` / `npm run test`（765件）/ `npm run build` すべてパス。
実機（`npm run dev` + ヘッドレスChromium）で描画を確認しながら、
奥半分しか塗られない・左右が逆・岩盤が額縁に見える、の3点を潰した。
