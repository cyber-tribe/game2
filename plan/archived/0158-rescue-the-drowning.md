# 0158 rescue-the-drowning

## 面ごとの設定の8つ目

原作は各面の開始前に10項目を○×で示す（`docs/original-maps.md`）。
`plan/archived/0152`／`plan/archived/0153` で7つを取り込んだ。残る3つのうち、**操作**である
「溺れた人間の救出」をここで入れる（あと2つは表示なので別のPR）。

○×の形が意味を持っている。**No.1〜15 は全面×**で、No.16 以降おおむね○、
その後 No.26 と No.39 でまた落ちる。序盤は水が単に死であり、救出は
キャンペーンが「スコップを覚える」段階から、敵の洪水・津波と付き合う
長い中盤へ移るところで手渡される。中盤の恩恵であって、また取り上げられる
こともある——という線が表にそのまま出ている。

## 救出そのもの

game2 の溺死は既に**息継ぎのカウントダウン**であり、陸に戻れば全快する
（`systems/drowning.ts`）。だから救出は新しい生死判定ではなく、
**民が自力でできなかったことをプレイヤーが手でやる**操作でよい。

- タップ地点から `RESCUE_RADIUS = 6` タイル以内で、**自分の**溺れている
  民のうち一番近い1人を、一番近い陸へ移す。`Drowning` を外し、
  `MoveTarget`（さっきまで泳いでいた先＝海の中）も落とす。
- **1タップ1人。** 範囲内を全員助けると、これは操作ではなく奇跡になる。
- **マナは取らない。** ○×表が並べているのは操作であって奇跡ではない。
  マナを取れば、マナが苦しい面＝人が溺れている面でちょうど使えなくなる。
- **敵は助けない。** 他陣営の民を海から拾うのは原作の言う救出ではないし、
  他人の民を取る道は集結・魅了として既にある。
- 降ろす先は「建築可能な土地」ではなく**乾いた土地**。海から引き上げた
  人間はどこかに立たねばならず、目の前の岸が焼け跡や溶岩岩だからと失敗
  するのはおかしい。定住先を選ぶのは `settle.ts` の仕事で、そちらは
  違いを知っている。
- `RESCUE_SHORE_SEARCH = 8` 頂点以内に陸が無ければ**失敗する**。大洋の
  ど真ん中から半島まで運ぶのは救出ではなく瞬間移動であり、○×が渡して
  いる操作よりはるかに大きい。

## UI

スプログの隣に「救出」ボタン。アイコンは浮き輪——16pxで読める形であり、
10項目のうち唯一「与える」設定なので、危険物ではなく助けに見える必要が
ある。使えない面ではスプログと同じようにボタンを暗くする。
