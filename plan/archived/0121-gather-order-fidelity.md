# 0121 gather-order-fidelity

## 背景

原作記事の「神の啓示」の節に、集合の説明がある。

> 集合：（建物から出ている状態の）フィールド上の信者達を、シンボルへ集める。
> **その間、平地があっても新たな建物は一切建てない。** 最初に辿り着いた
> 信者は「リーダー」となり、以後一般信者はリーダーの元へ集うようになる。
> ヒーローが使えるステージであれば、このリーダーがヒーローに変身する。
> **よって多数の信者を合体させ、強力なヒーローを生み出すのに不可欠な操作
> である。** 敵陣へシンボルを立て、信者のまま攻め込むときにも使う。

原作はこれを**1つの指示**として説明している。game2は「集結」（合流）と
「集結シンボルへ」（行軍）の2つに分けているが、分けたことで原作の
3つの性質が「集結シンボルへ」から抜け落ちていた。

| 原作 | game2（変更前） |
|---|---|
| その間、新たな建物は一切建てない | 建てる |
| 最初にシンボルへ辿り着いた者がリーダーになる | 「集結」でしかリーダーが生まれない |
| 多数の信者を合体させる操作である | 「集結シンボルへ」では合流しない |

3つとも同じ原因から来ている。原作の1つの指示を2つに割ったとき、性質を
片方（集結）に寄せてしまい、もう片方（集結シンボルへ）が「リーダーの後を
歩くだけ」になっていた。

## 症状

### 行軍が定住に化ける

追従する民はリーダーに追いつくと`MoveTarget`を失う。`settle.ts`は
「seekingで`MoveTarget`が無い」民を家にするので、**追いついた民が
その場で家を建てていた**。軍勢を集めるつもりで出した指示が、地図に小屋の
列を作る指示になっていた。

既存のテスト
`"under goToShrine mode, walks a lone leader to a relocated shrine and
settles it there"`が、まさにこの挙動を仕様として固定していた。

### 指示が自力で始動できない

`goToShrineSystem`は`leaderId`が無ければ**何もしない**。そして
`leaderSystem`は`behaviorMode === "gather"`のときだけ昇格させる。
つまり一度も「集結」を使っていないプレイヤーが「集結シンボルへ」を
選ぶと、モードは何の効果も持たず、民は`wanderTarget`に拾われて
勝手に定住していた。

## 変更

原作の1文が述べている通りに揃える。

1. **`settle.ts`**：`behaviorMode === "goToShrine"`の勢力は家を建てない。
   最終決戦中に建てないのと同じ扱い。
2. **`goToShrine.ts`**：リーダーが居ないときは全員をシンボルへ向かわせる。
   最初に着いた者が`leaderSystem`に昇格され、以後は従来通りリーダー追従に
   切り替わる。
3. **`leader.ts`**：`"gather"`に加えて`"goToShrine"`でも昇格させる。
   原作は昇格を「シンボルへ辿り着いたこと」に結び付けており、どちらの
   指示で行かせたかは条件ではない。
4. **`gather.ts`**：`"goToShrine"`でも合流する。合流こそがこの指示を出す
   理由（「多数の信者を合体させ、強力なヒーローを生み出すのに不可欠」）で
   あり、また 1. で家を建てなくなった以上、合流しなければ行軍先の群衆が
   何もしないことになる。

`gatherTargeting.ts`は`"gather"`のままにした。あれは「シンボル／リーダーへ
歩かせる」処理で、`goToShrine`は自前の同等処理を持っている。

## 敵AIへの影響

無し。`enemyAi.ts`が選ぶのは`fight` / `gather` / `settle`の3つだけで、
`goToShrine`は選ばない（`goToShrine`はプレイヤーの指示と、最終決戦の
行進のみ）。したがって`ENEMY_AI_ECONOMY_FLOOR`まわりの調整
（`plan/archived/0114-enemy-economy-floor.md`）は影響を受けない。

## 検証

- `settle`: 「集結シンボルへ」の勢力が家を建てないこと／同時に別勢力は
  普通に定住できること
- `goToShrine`: リーダー不在時に全員がシンボルへ向かうこと／他勢力を
  巻き込まないこと／ヘレンに拘束された民を引きずらないこと
- `leader`: `"goToShrine"`でも昇格すること／`"settle"`では昇格しないこと
- `gather`: 「集結シンボルへ」でも合流すること

既存テスト1本（上記の「settles it there」）は、原作が禁じている挙動を
仕様化していたので、到着して**何も建てない**ことを確認する形へ書き直した。

`npm run typecheck` / `npm run test`（731件）/ `npm run build` すべてパス。
