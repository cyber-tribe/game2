# 0105 トロイのヘレン —— 戦わない英雄

## 背景

六英雄の最後の1人。原作 #28:

> 女性英雄。**敵と戦わない**。敵信者を魅了・拘束して建物から引き離し連れ回す。
> ヘレンが死ぬと拘束は解ける。敵の人口・建築基盤を崩す

game2 のこれまでの英雄は全員「どこへ行って何を殴るか」が違うだけだった。
ヘレンは**殴らない**。実装上も、彼女だけは戦闘とハウスキャプチャの両方から
明示的に外れる。

## 「戦わない」の解釈

**「無敵」ではなく「攻撃力がない」**にした。彼女に触れた敵は無傷で、
**彼女は死ぬ**（強さがいくつでも）。

無敵にすると、戦わない英雄は「敵陣に置いておくだけで安全に人を吸い続ける
置物」になり、リスクが1つも残らない。逆に彼女が一方的に死ぬだけなら、
ただの弱い英雄である。**魅了半径 3 が戦闘距離 0.5 の6倍**にしてあるのが
この2つを繋ぐ部分で、近づいてくる敵は普通は触れる前に拘束される——
**拘束枠が埋まっていなければ**。

つまり彼女の生死は「何人抱えているか」で決まる。群衆に投げ込めば、あぶれた
1人が彼女を殺す。戦わない英雄が持つべき形はこれだと考えた。

## 拘束

- 拘束された民は `Charmed { by }` を持つ。**所有者は変わらない**（それは
  聖水の泉の仕事）。敵の民のまま、敵のために何もしなくなる
- 戦闘・ハウスキャプチャ・集結・戦闘指示・徘徊・**入植**からすべて除外する。
  最後の1つが「建物から引き離し」の実体で、連れ回された民が途中で家を建て
  始めたら意味がない
- ヘレンの背後をついて回る。**取られた場所に立ち止まったままなら敵は何も
  失わない**——歩かされることそのものが被害である

## 解除

`Charmed.by` が「生きていて Walker であって state が helen」でなくなったら
解除する。`world.isAlive` だけでは足りない。World は解放したIDを即座に配り
直すので、死んだヘレンのIDが1tick後には別のものになっていて、囚人が家や沼を
永遠に追いかけることになる。

解除を1番目に行うのも意図的で、同じtickの中で**別のヘレン**が拾えるように
なる。

## 検証

- 590 → 603テスト。魅了する／自軍は取らない／半径外は取らない／上限で止まる
  ／背後へ引きずる／拘束中は入植しない／未拘束の敵へ向かう／**死ぬと解ける**。
  戦わない側は、誰も殺さない／触れられれば死ぬ／**既に拘束した相手には襲われ
  ない**／敵の家に触れない／拘束された民も家を襲わない
- typecheck / build / `sprites:check` / `palette:check` 通過
- 本番ビルドを静的配信して実機確認。26個のコマンドが全てアイコン付きで並び、
  ヘレンが発動する（マナ70→43、拒否なし、コンソールエラーなし）ことを確認。
  拘束の様子そのものは敵の民が寄ってくる位置関係を作れなかったので、決定的な
  ユニットテスト側で固定している

## スプライトとアイコン

**手鏡**。他の英雄の武器はどれも縦に長く細いので、小さくて丸いものを持たせる
と「武装していない」が一目で読める。アイコンもコマンドパネルで唯一の非武器に
なる。
