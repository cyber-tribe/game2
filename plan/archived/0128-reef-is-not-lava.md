# 0128 reef-is-not-lava

## 背景

グラフィック面に差分が無いかを確認するため、`npm run dev` を立ち上げて
ヘッドレスChromiumで実際に描画させ、地形要素を1つずつ目視で監査した。
森・道・毒カビ・焼け跡・城壁・地下巨石・地割れ・火山はいずれも区別できて
いたが、**岩礁が溶岩に見えていた**。

海に浮かぶ岩礁が、黒い岩体＋縁のオレンジの発光——つまり噴きたての火山の
溶岩流とまったく同じ見た目で描かれていた。

## 原因

`IsoRenderer` は「岩かどうか」を `rockHardness > 0` だけで決め、溶岩の
発光量を `volcanoGlowIntensity(hardness, VOLCANO_ROCK_HARDNESS, ...)` で
出している。`applyReef` は `REEF_HARDNESS`（6）を置くので、岩礁は
6/20 = 30% の強さで光っていた。

## 判断

**暗い岩そのものは岩礁として正しい。** 原作は岩礁を
「海底火山を噴火させ海上に岩礁を作る」ものだと書いており、火山性の黒い岩で
あることに矛盾はない。

**間違っているのは火である。** 岩礁は既にそこにある岩であって、溶けては
いない。しかも実害がある——プレイヤーが自分で築いた防波堤が、敵の火山の
溶岩流と一目で見分けられない。津波を防ぐために海岸をどこまで塞いだかを
確認したい場面で、自分の岩礁がどれか分からない。

## 変更

`volcanoGlowIntensity` に `coldHardness`（既定 `REEF_HARDNESS`）を足し、
発光をその上の分だけで計算する。

- 岩礁（硬度6）は発光0になる
- 火山は従来通り光り、**硬度6まで冷えた時点で光が消える**（従来は0まで
  光り続けた）

後者は同じ規則を裏から読んだだけである——「岩は、岩礁より熱い間だけ光る」。
`raiseVertex` が硬度を削って冷ましていく既存の演出はそのまま残り、消える
タイミングが早くなる。

新しい `reef` レイヤーを `Heightmap` に足す案も検討したが、16箇所の
Heightmap リテラル（テストヘルパ）を触ることになる上、岩礁と冷えた火山岩を
別の物質として描き分けたいわけではない（どちらも冷たい火山性の岩である）。
硬度の下限として表現する方が、言いたいことに正確である。

## 検証

- 岩礁の硬度では、どの時刻でも発光が0であること
- 岩礁の硬度より1硬いと光り、1柔らかいと光らないこと
- 既存の「完全に冷えたら0」「硬いほど明るい」「時間で脈打つ」はそのまま

実機で海に岩礁を2キャストして描画し、オレンジの発光が消えて冷たい黒岩の
帯として読めることを目視確認した。

`npm run typecheck` / `npm run test`（755件）ともにパス。
