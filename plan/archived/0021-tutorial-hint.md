# 初回プレイ時に核ループを示すヒントを表示する

## 背景

`plan/0019`・`plan/0020`と同じく、ユーザーから共有されたスーファミ版
参考ゲームの初心者向け攻略要約がきっかけ。攻略要約が繰り返し強調して
いたのは「自分の民を見つける→その周囲を平らにする→家を建てさせる→
人口を増やす」という、何を置いてもまず覚えるべき核ループだった。

`Hud.ts`のコメントにある通り、PIXI canvas上のHUDは意図的に「状態表示
のみ」としており操作方法の案内を持たない。そのため初めてこのゲームを
開いたプレイヤーには、画面上のどこにもこの核ループへの案内がなく、
「何をすればいいか分からない」→「何が面白いのか分からない」に
直結していた可能性が高い。

## 対応

`index.html`にHUD・地図を邪魔しない`#tutorial-hint`という固定表示の
バナー（ツールバーの直上）を追加し、「まずは自分の民（丸いマーク）の
周りをタップして地形を平らにしよう。家が育ち、人口とマナが増えて
いく。」という一文を表示する。

- `pointer-events: none`のため、地図のタップ判定を一切妨げない。
- `main.ts`の`layout()`が測るツールバーの高さに合わせて`bottom`を
  動的に設定するため、ツールバーの行数（画面幅）が変わっても重ならない。
- プレイヤーが実際に地形編集（既定の隆起/沈降タップ）を1回行うと
  即座にフェードアウトして消える。何もタップしないまま眺めている
  プレイヤーのために15秒の自動タイムアウトも用意した。
- HUD自体（状態表示のみという既存方針）は変更していない。あくまで
  ツールバー領域に増設したHTMLオーバーレイの一部。

## テスト

- `npm run typecheck` / `npm run test`（177件、ロジック変更なし） /
  `npm run build` すべて成功。
- ヘッドレスブラウザで、起動直後にヒントが表示されること、地図を
  タップして地形編集が成立すると（`mana`が実際に減ることで確認）
  ヒントが消えることをスクリーンショットで確認した。
