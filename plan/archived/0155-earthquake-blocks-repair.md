# 0155 earthquake-blocks-repair

## 原作「地震が続いている間は修復が出来ない」

game2 の地震は詠唱した瞬間に終わっていた。地割れは残るが地面は止まって
いるので、**次のタップで埋め戻せる**。これでは地震はマナ税でしかない——
守る側はスコップ1回を払って何も失わない。原作が地震を「中」位の攻撃奇跡
として並べているのは、割れた地面がしばらく動き続け、その間は手が出せない
からである。

原作は地震を、竜巻・嵐・火柱と並べて**持続時間が系統レベルで伸びる**奇跡
として挙げている（`docs/original-miracles.md`）。つまり地震には長さがある。

## 揺れをどう持つか

`Quake` コンポーネント（`remaining` と `path`）を1体のエンティティとして
置き、`createQuakeSystem` が毎tick減らして0で消す。竜巻・渦巻き・火柱と
同じ作りである。

**円ではなく線で持つ。** 地割れは10頂点ほどの線なので、中心と半径では
遠い端を取り逃すか、触っていない地面まで凍らせるかのどちらかになる。
`applyEarthquake` が裂いた頂点列をそのまま返すようにし、`createQuake` が
それを抱える。`isGroundShaking` は線からの距離で判定する。

半径 `EARTHQUAKE_SHAKE_RADIUS = 2` は余白である。地割れは1頂点幅なので
余白ゼロだと真横にスコップを立てて横から土を寄せられ、原作が禁じている
修復そのものが通ってしまう。2 は game2 が既に「地震がおおよそ乱す範囲」
として使っている `DEFAULT_EARTHQUAKE_RADIUS` と同じ値。

`applyEarthquake` の中で作らないのは、`world/heightmap.ts` が ECS を知ら
ないからである（テストや敵AIの下ごしらえは world 無しで地面を裂く）。

## 何を止めて、何を止めないか

止めるのは**スコップ**——土地上下・平坦化・自動整地。プレイヤーも敵AIも
同じである（`enemyTerraform.ts`）。自陣に地割れを走らされた神が次のパスで
埋め戻せるのに、撃たれたプレイヤーが埋め戻せないのでは筋が通らない。

止めないのは**奇跡**。花は揺れていても地割れを埋める。原作の一文は「修復」
＝手作業についてであり、奇跡を奇跡で返せることは地震の価値を損なわない。
安い手作業の修復を封じることが差の全部である。

自動整地は「揺れている区画だけ計画から落ちる」。敵陣の制限と同じ扱いで、
村の端に地割れが走っても残りは整地できる。

## 検証

- `npm run typecheck` / `npm run build` パス、テスト883件パス（+18）。
- `quake.test.ts` 12件——線として持つこと（両端が揺れ、間の未接触地は揺れ
  ない）、余白の内と外、複数の地震、時間で切れること、空の地割れで
  エンティティを作らないこと。
- `applyEarthquake` の返り値3件（裂いた順の頂点列／地図外で空／端で打ち切り）。
- 敵AI 3件——神の地震も地面を揺らすこと、神自身も揺れている間は整地
  しないこと、揺れが切れれば再開すること。
