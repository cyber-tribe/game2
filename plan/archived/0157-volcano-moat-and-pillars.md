# 0157 volcano-moat-and-pillars

## 原作「火山の外周に水たまりができ、火柱が数本発生する」

game2 の火山は**山と溶岩だけ**だった。噴火が済めば、あとは固定の地形が
残る——集落はその周りに建て直せばよい。原作の火山が「大」位の値段に見合う
のは、噴火の後も危険が動き続けるからである。

## 水たまり

円錐の裾（`VOLCANO_PUDDLE_RING = 2` 頂点外）に、海面まで沈む頂点を
`VOLCANO_PUDDLES = 5` か所melt する。溶岩は既に水で止まる仕組みがあるので
（`flowLava`）、水たまりを溶岩より先に作れば、原作の言う「溶岩流をそこで
止める」はそのまま出る。

**閉じた堀にはしない。** 全周を水にすると火口が封じられ、溶岩流が一滴も
出なくなる——溶岩の流れは前のPRでわざわざ作った、この奇跡の性格そのもので
ある。半径3の円周は約20頂点なので、5か所は4分の1ほどを塞ぐ。溶岩は隙間を
選んで出ていく。「水たまり」（複数・点在）という言葉どおりで、全周でも
1か所でもない形が一番おもしろい。

角度は等間隔＋ジッター。同じ噴火が二度と同じ模様にならず、それでいて
5か所が片側に固まることも無い。

水たまりも `covered` に含める。新しい池の中に取り残された家は、溶岩の下の
家と同じく消える。

## 火柱

`VOLCANO_FIRE_PILLARS = 3`（「数本」）を、火口から
`VOLCANO_FIRE_PILLAR_RING = 4` タイル外に、外向きに立てる。

**円錐の上には立てない。** 火柱は高い方へ寄る（`plan/archived/0150`）ので、斜面に
生まれた火柱は自分が出てきた山を登り返して何も焼かない。裾より外から
外向きに押し出して初めて、集落の側へ歩いていく。

**破壊より先に立てる。** `World` は破棄したエンティティのIDを次の
`createEntity` へそのまま渡す（`systems/effects.ts`）。後から立てると、
この噴火が埋めた家のIDを火柱が引き継ぎ、呼び出し側が `world.isAlive` に
訊いたとき「生きている」と答えてしまう。実際に敵AIのテストがこれで落ちた。

## 検証

- `npm run typecheck` / `npm run build` パス、テスト896件パス（+10）。
- 水たまり5件——数と位置（裾のリング上）、`covered` に入ること、溶岩が
  水の上には乗らず・それでも外へ出ること、0を渡せば作らないこと、
  元から海だった所は二重に数えないこと。
- 火柱5件——本数と外向きの向き、円錐から離れて立つこと、片側に固まらない
  こと、火口を渡さなければ立たないこと、埋めた家のIDを奪わないこと。
- 円錐と溶岩そのものを見ている既存テストには `puddles = 0` を渡した。
  水たまりは別の性質なので、別のテストで見る。
