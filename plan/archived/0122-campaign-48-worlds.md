# 0122 campaign-48-worlds

## 背景

原作記事の概要と賛否両論点に、キャンペーンの規模がはっきり書かれている。

> 敵として**16人の神**が登場し、**各3ステージ**が用意されている。

> ステージ数が**全48面**と少ない。他機種版は数百面が当たり前。

game2 のワールドは6面だった。また `docs/game-system.md` 10節は
「約500の固定ワールド」と書いていたが、これは一般のゴッドゲーム調査
（初代『POPULOUS』や他機種版）から来た数字で、game2 が再現の対象に
している**SFC版の48面ではない**。`worlds.ts` にも
「World-count progression (500 worlds) is still out of scope」という
コメントが残っていた。

つまり、正しい目標値が分からないまま「遠すぎる目標だから後回し」に
していた。原作記事が取れたことで目標は48面と確定したので、届く。

## アプローチ

### 神が単位である

原作は「16人の神、各3ステージ」と書いている。プレイヤーが相手として
体験する単位は**面ではなく神**で、同じ神と3戦する。そこで
`GodDefinition`（16件）を作り、`WORLDS`（48件）はそこから生成する。

**神が決めるもの**（＝「誰と戦っているか」）
- 系統（`enemySchool`）
- 気質（`enemyPersonality`）
- 領土の地形（`terrain`）と地形操作の制限（`terrainEditRule`）
- その神の1面目で解禁される奇跡（`unlocks`）
- 自陣を掘らせるかどうか（`territoryEditable`）

**面の位置が決めるもの**（＝「どれだけ難しいか」）
- `enemyDecisionInterval` と `enemyAggressionThreshold`

難易度は48面を通した**1本の曲線**として6→2へ下げる（`difficultyStep`）。
神は難易度そのものではなく、その上に描かれた登場人物である。この分け方は
既存の設計判断（`EnemyPersonality` / `enemySchool` の doc comment が
「単調な難化の軸ではない」と明記している）をそのまま48面へ広げたもの。

### 奇跡の解禁

`unlocks` は神の1面目で入り、その神の3戦は**同じ手札**で戦う。手に
入れた直後に3戦あるので、覚える時間が取れる。

16神の `unlocks` を合計すると `ALL_MIRACLES`（28個）にちょうど一致する
（テストで検証）。最後の面ですべて解禁されるという既存の不変条件も
そのまま満たす。

### 系統と解禁の順序

敵の神は系統の代表奇跡が解禁されていないと地震へ落ちる
（`enemyMiracles.ts`）。世界選択が「火の神」と表示しているのに火を
一度も撃たないのは、プレイヤーに見える嘘になる。そこで**最初の6神を
1系統ずつ**にし、それぞれが自分の代表奇跡を解禁する順にした。

- 1〜6: 地・植物・気・人・火・水（`docs/original-miracles.md` の列挙順）
- 7〜12: 同じ6系統を別の気質で再訪し、地形を作る側の奇跡を渡す
- 13〜16: 残りの英雄と、試合を決める奇跡（地下巨石・最終決戦）。
  この4神の領土はプレイヤーの直接操作を受け付けない

「どの面でも、その面の神の代表奇跡が解禁済みである」ことをテストで
検証している。

### 神の名前

原作のプレイヤーは「ゼウスと人間の女性の間に生まれた青年」で、英雄も
ペルセウス・ヘラクレス・オデュッセウス・アキレス・アドニス・
トロイのヘレンとギリシャ由来である。敵の神もギリシャの神々から取った。

## 検証

`src/game/worlds.test.ts` に追加。

- 神が16、各3ステージ、合計48であること
- 1神の3面が系統・気質・地形・地形操作制限・解禁奇跡まですべて同じで
  あること（違うのは難易度だけ）
- どの面でも、その面の神の代表奇跡が解禁済みであること
- 6系統すべてが登場すること
- 解禁が重複なく、合計が `ALL_MIRACLES` と一致すること

既存の不変条件テストはすべてそのまま通る。

- 敵AIの速さ・攻撃性が後戻りしない
- `allowedMiracles` が減らない／最終面で全解禁
- `enemyTerritoryEditable` が一度falseになったら戻らない
- `instantDrowning` は岩（溶岩地帯）の面だけ

`npm run typecheck` / `npm run test`（736件）/ `npm run build` すべてパス。

## UI

世界選択リストは元から `overflow-y: auto` でスクロールするので、48件でも
そのまま並ぶ。難易度表示は `難易度{n}/{WORLDS.length}` なので自動で
`/48` になる。パスワードはワールドidそのもの（`gaia-2` など）で、
従来通り打てる長さに収まっている。
