# 二本指でマップを回転できるようにする

## 要望

「二本指でマップを回転させられるようにしてください」

## 対応

`main.ts`のポインタ処理を、`pointerId`ごとに複数の接触点を追跡できる
ように拡張した。

- 2本目の指が触れた時点で、既存の「タップ判定／ドラッグでパン」の
  1本指ジェスチャーを中断し、回転ジェスチャーに切り替える。
- 2本の指を結ぶ線の角度を毎フレーム計測し、その変化量ぶん
  `renderer.view.rotation`を更新する。地図（`IsoRenderer`の地形）も
  `EntityLayer`（家・ウォーカー・沼など）も`renderer.view`の子なので、
  一緒に回転する。HUDは`app.stage`の別の子（`renderer.view`の外）
  なので回転の影響を受けず、常に正立表示のまま。
- 回転は2本指の中点を軸に行う（一般的な地図アプリの回転ジェスチャーと
  同じ「つまんだ場所を中心に回る」感覚）。実装は「回転前にその中点の
  ローカル座標を求め、回転後も同じローカル座標が同じ画面座標に
  留まるように`view.position`を再計算する」という、ピンチズームの
  中心固定と同じ手法。
- 2本指ジェスチャーがあったかどうかをジェスチャー全体（最初の指が
  触れてから最後の指が離れるまで）で記憶しておき、指を1本に戻したり
  最後の指を離したりした際に、意図しないタップ（地形編集）やパンの
  再開が起きないようにした。

地形タップ判定（`IsoRenderer.pickVertex`・`renderer.view.toLocal`）
自体は変更していない。PixiJSの`toLocal`は`position`/`rotation`/
`scale`を含む変換全体を正しく逆変換するため、回転後にタップしても
狙った頂点を正しく拾える。

## テスト

- `npm run typecheck` / `npm run test`（190件、ロジック変更なし） /
  `npm run build` すべて成功。
- ヘッドレスブラウザで、canvasに対して`pointerId`の異なる2つの
  `PointerEvent`（`pointerType: "touch"`）を合成し、中点を軸に約90°
  ひねる二本指ジェスチャーを再現。地図の稜線が横向きから縦向きへ
  実際に回転し、家・ウォーカーも地形と一緒に回転することを
  スクリーンショットで確認した。
- 回転後に地図をタップし、その地点で家・ウォーカーの状態が変化する
  （＝タップ判定が回転後も画面上の見た目と一致している）ことを
  確認した。

## 積み残し

- 回転中は`clampPan`（パンの範囲制限）を適用していない。回転後の
  正確な画面外判定には、回転を考慮したバウンディングボックス計算が
  必要になるため、今回はスコープ外とした。大きく回転させたまま
  1本指でパンすると、地図を画面外まで動かせてしまう可能性がある。
- 画面回転（`resize`イベント、実際にはこのゲームは縦持ち専用のため
  頻度は低い）が発生すると`layout()`が`centerOn()`で位置を再計算する
  が、`rotation`自体はリセットしないため、稀に位置と回転の組み合わせが
  ずれる可能性がある。
