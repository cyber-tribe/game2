# 0101 聖水の泉 —— 英雄を奪う

## 背景

ユーザーが挙げた「落としてはいけない相互作用」のうち **聖水 → 英雄寝返り**。

原作 #27:

> 落ちた信者が**敵側へ寝返る**。英雄まで寝返る可能性があり、強い英雄を奪えば
> 形勢逆転できる。再度落ちると元へ戻る場合もある

**これは英雄が名前と固有特性を持った後（plan/archived/0100）でなければ意味を
成さない。** それ以前の game2 では英雄は「騎士か守護者か」でしかなく、奪って
も奪われても「ターゲティングのルールが1つ変わる」だけだった。ヘラクレスや
アキレスが居る今、敵の英雄を奪うことは初めて「形勢逆転」になる。

## 実装

`HolyWater` は `Swamp` と同じ形（半径 + 容量）にした。**同じ種類のもの**
だからである——踏み込んだ者に決まった回数だけ何かをして、消える一画の地面。
違うのは沼が消し、泉が奪うことだけ。

泉には `Owner` が付き、**その所有者の側に**歩いて出てくる。だから自分の陣地
ではなく敵の玄関先に置く価値がある。

### 英雄を特別扱いしない

`isHeroState` を見ていない。敵のヘラクレスを取ることが原作の言う「形勢逆転」
であって、**「奪う価値のある唯一の駒だけが助かる泉」は沼の劣化版**でしかない。
奪われた英雄は強さも英雄種別も位置もそのまま、所有者だけが変わる。

### 「再度落ちると元へ戻る」はルールを書いていない

泉は「自分の所有者ではない民」だけを取る。だから互いが泉を持てば、同じ民が
両者の泉を行き来する。原作のこの一文に対して専用の分岐を書く必要はなかった。

### リーダーの取り違え

`leaderSystem` は `leaderId` が**生きていて Walker であること**しか見ておらず、
所有者を見ていなかった。寝返りが入ると、**奪われた側が敵の駒を自軍リーダー
として指し続ける**（集結先がそこになり、英雄化の奇跡が敵ユニットに掛かる）。
所有者の一致も条件に加えた。寝返りが初めて作った不具合ではなく、寝返りが
初めて**到達可能にした**不具合である。

## 容量とコスト

- `HOLY_WATER_CAPACITY = 3`。泉の価値は量ではなく**誰が落ちるか**であり、
  原作もそう書いている（「強い英雄を奪えば」）。3なら英雄1人と護衛2人で
  転換点になり、20なら軍を静かに消化するだけで置き場所が意味を失う
- `HOLY_WATER_MANA_COST = 45`。同じ大きさの沼が消すのに対し、こちらは奪って
  向きを変えて返す。戦力差でいえば概ね2倍の働きなので、沼より高い

## 描画

沼の泥と正反対の**明るく静かな水**にし、**所有者の陣営色で縁取った**。
プレイヤーが泉について下す判断は「どちら向きか」が全てなので、無地の水たまり
は読みようのない罠になる。

## 敵AIは触っていない

英雄のときと同じ理由。泉を**うまく**置くには敵ウォーカーの通り道を読む必要が
あり、それは別のAIであり難易度の変更でもある。

## 検証

- 546 → 554テスト。敵は寝返る／自軍は寝返らない／半径外は無事／**英雄は強さ
  も種別も保ったまま寝返る**／容量で涸れる／相手の泉で戻る／転換が通知される
  ／奪われた陣営が新しいリーダーを選び直す
- typecheck / build / `sprites:check` / `palette:check` 通過
- ブラウザ実機（最終戦線）で泉を発動。所有者色の縁を持つ明るい水として地面に
  描かれ、20秒後も（誰も落ちていないので）涸れずに残ることを確認。コンソール
  エラーなし

## 残件

「落としてはいけない」相互作用で残るのは **竜巻 → 渦巻き** と
**ハリケーン → 沼／亀裂**。どちらも「動く危険地帯」という新しい仕組みが要る。
