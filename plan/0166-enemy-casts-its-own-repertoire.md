# 0166 enemy-casts-its-own-repertoire

## 敵の手札はプレイヤーの手札ではなかった

実機で遊んで見つけた。No.1 で5分回しても敵が奇跡を1つも撃たず、災害箇所
表示のマーカーが一度も出ない。原因を追って `EnemyMiracleEvent` が29個中
10個しか持っていないと分かり、**面の手札から撃たせる**修正を書いた。

書いてから資料を読み直して、前提が間違っていたと分かった。攻略資料の
各面ページには**「敵の神技」という独立した欄**があり、game2 はそれを一度も
見ていなかった。

> No.1 敵の神技：**土地上下とマグネットのみ。しかも反応が極めて遅い。**

No.1 はプレイヤーに火柱・ペルセウス・アーマゲドンを配る。**神はそれを
使わない。** 最初の面が易しいのは手札ではなく神の側である。書きかけの修正を
実機で試すと、開始84秒で神が火柱を投げてきた——忠実化ではなく改悪だった。

同じ誤りが他にもあった。No.19「ほぼアドニスのみ。**津波を持っているが、
まず使わない**」、No.23「自分の使用神技と同様。**ただし、ほとんど仕掛けて
こない**」。**No.23 の神が沈黙していたのは、むしろ正解に近かった。**

## 資料の欄をそのまま持つ

48面ぶんの原文を `docs/original-maps.md` に転記し、`WorldDefinition` に
3つのフィールドを足した。

- **`enemyMiracles`** —— その神が撃つもの。**空なら本当に何もしない**——
  英雄化も最終決戦も含めて。「土地上下とマグネット**のみ**」と書かれた面は
  No.1 だけで、最初の面が易しい理由はそこにある（手札が小さいからではなく、
  神が手を出さないから）。最初の実機確認で、火柱は止まったのに守護者化が
  残っていて気付いた。
- **`enemyHero`** —— その神がなる英雄。資料が21面で名指ししている。
- **`enemyCastRate`** —— 撃つ**頻度**。持ち物とは別の軸で、資料が言及して
  いる4面だけに付く（No.37「執拗に」＝0.5、No.1・19・23 は撃たない側）。

「自分の使用神技と同様」と書かれた15面は、プレイヤーの手札のうちAIが撃てる
ものを写した。それが資料の言っていることである。

## 英雄の保留が解けた

「ヘラクレスやアキレスを上手く選ぶには地形を読む必要があり、それは別物の
AIで、難易度の変更でもある」という保留がコードに残っていた。**原作も選んで
いない**——面ごとに決まっている。だからデータで決まる。

資料が名指しした英雄は**その神のもの**なので、プレイヤーの手札の許可は要らない
（No.29 の神はヘラクレスになるが、プレイヤーにヘラクレスが配られているとは
限らない）。名指しの無い面のペルセウスと、負けているときの守護者化は game2
自身の推測なので、従来どおり手札で縛ったままにした。

## 何が変わって、何が変わらないか

- 系統の代表を持っている神は、従来どおりそれを撃つ（`chooseAttack` は
  signature を先に見る）。「沼。ひたすら沼」がそのまま出る。
- 代表を持たない神は、自分の持ち物のうち**自系統の一番高いもの**、それも
  無ければ持ち物の一番高いものを撃つ。「安い物で埋め合わせない」という
  既存の習慣と同じ。
- `castSignature` を `castAttack` に改め、火柱・竜巻・ハリケーン・嵐・
  毒カビ・渦巻き・津波の撃ち方を足した。向きを持つものは自陣のマグネット
  から標的の向こうへ。敵は常にレベル1なので持続時間などは既定値。
- `HERO_MANA_COST` を `main.ts` から `constants.ts` へ移した。両陣営が同じ
  英雄に同じ額を払う以上、表は1つでよい。

## 検証

- `npm run typecheck` / `npm run build` パス、テスト1027件パス（+14）。
- `enemyMiracles.test.ts` 11件——何も持たない神は撃たないこと、手札を無視して
  自分の持ち物から撃つこと、代表を高い物より先に取ること、代表が無ければ
  自系統の高い物、自系統が無ければ他系統、買えなければ貯めること、向きが
  自陣から外を向くこと、名指しの英雄になること、その英雄に手札の許可が
  要らないこと、名指しが無ければペルセウスに落ちること。
- `enemyMiracles.test.ts` にもう1件——持ち物が空なら英雄化もしないこと。
- **実機確認**（製品ビルドをヘッドレスで各3分）——資料の記述と突き合わせた。

  | 面 | 資料 | 観測 |
  |---|---|---|
  | No.1 | 土地上下とマグネットのみ | **何も撃たなかった**（修正前は84秒で火柱、次に94秒で守護者化） |
  | No.7 | 沼。ひたすら沼 | 98秒 敵が沼を作った |
  | No.23 | ほとんど仕掛けてこない | 174秒 敵が火柱を立てた（3分で1回） |

- `worlds.test.ts` 4件——No.1 が空であること（かつプレイヤーの手札は空で
  ないこと）、持ち物がAIの撃てるものだけであること、英雄を名指しする21面、
  頻度をいじる4面。
