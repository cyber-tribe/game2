# 0091 Walkerと建物のスプライトを精細化する

## 依頼

> スプライトにもっとピクセル数を割いて良いので精巧に作ってください
> 家も人もです

plan/0090 で walker のスプライトパイプラインを通したが、絵そのものは
5x9ピクセルのまま（旧 `Graphics` 版の見た目を維持する方針だった）。
建物にいたっては手続き描画のままだった。本タスクで**両方を実際に作り込む**。

## 解像度

| | 旧 | 新 |
| --- | --- | --- |
| walker | 5x9 art px → 6.5x11.7 画面px | 11x18 → **11x18 画面px** |
| leader | ×1.8 | ×1.4（プリュームは絵に焼き込み） |
| hut | 12px幅（手続き描画） | **26x28** |
| lodge | 16px幅 | **32x34** |
| manor | 20px幅 | **40x44** |
| castle | 30px幅 | **56x56** |

walker は画面上のサイズも1.7倍にした。**解像度だけ上げて画面サイズを
据え置くと、スプライトを0.6倍で描くことになる。** nearest 補間の
スプライトを非整数倍で縮小すると行ごと落ちるので、増やしたディテールが
そのまま失われる。64pxタイルに対して walker は幅11px（約1/6）、
hut は幅26px（約1/3）で、原作の密度感に近い。

## 4フレーム歩行サイクル

2フレーム（`stepping: boolean`）を4フレーム（contact / passing /
contact / passing）に増やした。この解像度では2フレームは「震え」に
見える。4フレームなら、passing で全身が1px持ち上がり、2つの contact が
逆の腕を振るので歩いて見える。

上下動（bob）は**絵に焼き込んだ**（`BOB_BY_FRAME`）。旧実装は
スプライトを画面座標で小数px上下させていたが、nearest 補間のスプライトを
サブピクセル移動させてもチラつくだけで、絵側の1pxと二重にかかる。

### 見つけたバグ: 位相オフセットの同期

サイクルを離散化した結果、`walkCycle` の位相オフセット
`pos.x * 3 + pos.y * 5` が**整数**であることが問題になった。4フレーム周期に
対して整数オフセットは mod 4 でしか効かないため、多数の walker が
完全に同期して歩く。旧実装は同じ値を `sin()` に渡していたので任意の値で
分散していた。

`WALK_PHASE_SPREAD = 0.37` を掛けて非整数化した。テストが実際にこれを
検出している（「異なる位置の walker が同期しない」が失敗した）。

## 光源方向を地形に合わせた

`IsoRenderer` の `LIGHT_DIRECTION` は `(+x, -y)`（north-east）。この2方向は
どちらも画面右へ射影される（`(+32,+16)` と `(+32,-16)`）ので、
**画面右を向く面が明るく、左が影**になる。

旧 `pixelArt.ts` の建物は `drawWalls` で **left を明るく** 描いており、
地形と建物で太陽の位置が食い違っていた。作り直す機会なので地形側に
揃えた。

## 作画で判明したこと

**値のコントラストが全て。** 最初の hut は屋根と壁に似た茶色を使い、
実寸では一個の茶色い塊にしか見えなかった。明るい屋根／暗い壁という
**値の分離**を作り、テクスチャは面の内側で1段動かすだけに留める
（屋根と壁の境界と競合させない）と読めるようになった。

**等角の稜線は必ずタイル軸に沿わせる。** 最初の寄棟屋根は稜線を
画面垂直に取った。画面垂直は footprint ダイヤモンドの*対角線*であって
タイル軸ではないため、屋根の上半分が幅1pxの棘に潰れ、全体が平たい円盤に
見えた。錐屋根（`_pyramid_roof`）は4面すべてがタイル軸上の三角形なので
この曖昧さがなく、茅葺きの小屋としても正しい形になる。manor の切妻
（`_gable_roof`）は稜線を実際のタイル軸上に置いたので、画面上では2:1の
斜線になる。

**アウトラインは図を食う。** 11x18 の人物に1pxの黒アウトラインを回すと、
2px幅の脚は「色2px＋黒2px」になって下半身が黒い塊になる。ズボンと
ブーツをパレットの明るい側に寄せて解決した。

**描画順のバグ。** 腕を脚より先に描いていたため、前に振り出した腕の
手（肌色1px）が脚に上書きされて消えていた。腕を最後に描く。

## 生成物

```
src/assets/sprites/walkers.png   192フレーム / 176x216px / 3.8KB
src/assets/sprites/houses.png      8フレーム / 896x56px  / 2.8KB
```

建物は4レベル×2陣営の8枚のみ。建物はアニメーションせず、陣営色は旗に
しか及ばない（plan/archived/0085: 原作は建物全体を陣営色に塗らない）。

walker と建物でアトラスを分けたのは、フレームサイズが5倍違うため。
一つの均一グリッドに入れると 11x18 の walker が全部 56x56 に
パディングされる。

## src/render/pixelArt.ts を削除した

`drawWalkerSprite` に続いて `drawHouseSprite` とその補助
（`drawWalls` / `drawHipRoof` / `drawCastle` / `footprint` ほか）も
不要になり、残ったのは `Facing` 型だけだった。型は
`walkerSprites.ts` へ移してファイルごと削除した。**描画コードはすべて
Python 側に移った。**
