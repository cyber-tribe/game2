# 0137 hud-clear-of-minimap

## 見つけ方

`plan/0136`（土地上下不可ステージ）の実機確認をしていて気づいた。
HUDに出るはずの「地形操作: 土地上下不可」が、末尾の数文字しか
見えていない。

原因はこの面に固有のものではなかった。HUDのテキストは画面左上
（10, 10）に置かれ、**ミニマップも同じ角に置かれている**。
`plan/0130` でミニマップを左上へ動かしたときから、HUDの2行は
ずっと岩盤の下に隠れていた。常時出ている「地形: 草原」の行も含めて、
`raiseOnly` の面の「隆起のみ可」も同じである。

## 直したもの

### 1. HUDをミニマップの下へ

`Minimap.ts` に `minimapHeight(size)` を足し、`main.ts` の `layout()` が
それを見てHUDのY位置を決めるようにした。

`MINIMAP_SIZE` をそのまま使わなかったのは、**島は地図より背が高い**
からである。地図は岩盤の上面にはめ込まれていて、その下に本体が
すぼまり、破片が虚空へ垂れている。`size` を基準に下へ置くと、島の
中に置くことになる。破片の長さは `drawIsland` と `minimapHeight` が
`shardLength(i)` を共有するので、描画と申告がずれない。

`Hud.setTopInset` は `setTopOffset` に改名した。渡すものが
「セーフエリアの余白」から「左上の角のうち既に埋まっている高さ」に
変わったので、名前も合わせる。

### 2. 文字に黒縁を付けた

隠れていたものを見えるようにする以上、**全ての地形で読めるか**を
確かめる必要がある。HUDの白文字は世界の上に直接乗っており、地形は
溶岩地帯のほぼ黒から雪原のほぼ白まである。1色で全部に効かせる方法は
縁取りで、これはツールバーのアイコンが既に守っている規則でもある
（`tools/sprites/icons.py`：「Every icon has an ink outline」）。

隠れていた不具合を直しただけで終わると、雪原で同じことが起きる。

## 検証

- `npm run typecheck` / `npm run build` パス。
- `npx vitest run` 799件パス（+3）。
- `Hud.test.ts` に `setTopOffset` の1件、新規 `Minimap.test.ts` に
  `minimapHeight` が地図の一辺より大きい件と、地図に比例して伸びる件。
- 実機で撮影して、2行とも島と破片を避けて読めることを確認した
  （制限行を出すため一時的に1面目を `neither` にして撮り、戻した）。
