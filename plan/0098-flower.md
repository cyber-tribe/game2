# 0098 花 —— 荒地の修復

## 背景

`docs/original-miracles.md` の相互作用のうち「花 → 荒地修復」。
plan/archived/0095（地震の地割れ）と plan/archived/0096（火山の溶岩）が
**意図的に開いたまま残した輪**を、ここで閉じる。

原作の花（#7）は「荒れて建築不能になった土地を通常の平地へ戻します。
沼、地震による亀裂、火山で荒れた土地などを修復でき……溶岩にも有効」。

**3つの奇跡に同時に対抗する**のが花の価値である。単体の効果は小さいが、
それは「小さい奇跡」だからではなく、対抗手段だからそう見えるだけである。

## 実装

`applyFlower` が範囲内の:

- **地割れ**（`crevice`）を閉じる
- **火山の岩と溶岩**（`rockHardness`）を消す

沼は地形ではなく ECS のエンティティなので、既存の `collapseSwampsNear`
（地震が既に呼んでいるもの）を呼び出し側で使う。

### 地割れはフラグを下ろすだけでは駄目

地割れは床まで削られている。デフォルトの海面高では**床は水面下**なので、
フラグを下ろすだけでは畑ではなく池が返ってくる。海面のすぐ上まで戻す。

「通常の平地へ戻す」であって地形操作の代用ではないので、それ以上は上げない。

## 何も癒せないならマナを取らない

荒地がなければマナを消費する**前**に弾いて「ここには癒すものがありません」
と出す。沼も判定に含める必要があるため、`collapseSwampsNear` が**除去した
数を返す**ようにした（地震側は戻り値を無視するだけ）。

## コスト

8と安くした。**元に戻せる被害の大きさで値付けすると、荒れた地図を修復する
ことが現実的に不可能になる。** 花が一度に治すのは小さな一画で、地震は長い
亀裂を、火山は谷を埋める。

## 検証

- `npm run typecheck` 通過、`npm run test -- --run` 507件通過
- **地震で開けた地割れを閉じて建築可能に戻すこと**
- **火山の岩を消して建築可能に戻すこと**
- 地割れを水面より上へ戻すこと（池を返さない）
- 健全な地面には触れないこと、範囲外に届かないこと、
  癒すものがなければ空を返すこと（呼び出し側がキャストを拒否できる）
- `collapseSwampsNear` が除去数を返すこと
- 実ゲームで確認。地震で亀裂を開け、その上を花でなぞると**亀裂が通常の
  地面に戻った**。コンソールエラー0件
