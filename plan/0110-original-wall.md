# 城壁 —— 通行を妨げる最初の地形

原作 #12「信者の進行を遮る壁。英雄以外は越えられない」。

29個のうち、これだけが**移動そのものを変える**奇跡だった。それまでの
game2 のウォーカーは目的地へ直進するだけで、地形は「そこに居ると何が
起きるか」しか変えていない（亀裂は落ちると死ぬ、道は速い、毒カビは
削る）。壁は「そこへ行けない」であって、迂回する仕組みが無ければ
壁は単に**通り抜けられる絵**になる。だからこのPRの本体は壁ではなく、
`systems/movement.ts` の `stepAroundWalls` である。

## 経路探索を入れなかった

A* を敷けば「賢い」迂回になるが、64x64の頂点グラフを毎ティック、
全ウォーカー分たどることになる。入れたのは**局所操舵**で、ウォーカーは
自分の目の前しか知らない。

- まっすぐ進めるなら常にまっすぐ進む
- 進めないなら片側へ回り込む（45°→90°→135°の順に空いた方向を探す）
- **どちら側へ回ったかを覚える**（`Detour` コンポーネント）。覚えないと
  壁の正面で毎ティック左右を選び直し、その場で振動して動かない。
  正面から見た壁は左右どちらも同じに見えるからである
- まっすぐ進めるようになったら覚えたことを捨てる。これが「壁の端を
  回り込み終えた」瞬間になる

**三方を壁で囲んだ袋小路からは出られない。** これは欠陥として書いて
おくが、直すつもりはない。壁にできてよいことであり、全員分の経路を
毎ティック引き直すより遥かに安い。

## 壁は壊せなければならない

原作は壊し方に触れていない。しかし壊せない壁は、敵を囲って**戦わずに
勝つ**手段になる。そこで既にある方向性の奇跡を答えにした。

- **地震**（地割れ）が壁を断ち切る。地割れは方向を持つので、壁を壊すには
  壁を**貫くように狙う**ことになる
- **火山**（溶岩）が壁を埋める

値段の非対称がその意図である。城壁は塊1つで12、地震は20で頂点10個ぶんの
地割れを一直線に開ける。**囲うのは時間を買う手段であって、勝ち方では
ない。**

## 一度の詠唱で築けるのは塊1つ

半径1（5頂点の十字）。一撃で線を引かないのは、プレイヤーが方向を
指定していないのに向きを推測することになるからで、原作も壁の駒を
置いて繋いでいく。繋ぐ手間がそのまま長さの値段になる。

見た目は `wall` フラグに加えて地面を3段持ち上げている。持ち上げが
壁の実体ではない（急斜面はこのゲームで誰も止めたことがない）——
既存のメッシュ描画に陰影の付いた面を作らせるためだけのものである。

## 石の中に閉じ込めない

自分の立っている頂点が壁になったウォーカーは、その一歩だけ壁を無視する。
そうしないと、人の上に壁を築くのが**永久に動けなくする**手段になる。
壁を無料で消す方法はこのゲームに無いのだから、閉じ込めは詰みである。

## 計測

64x64、平坦、敵の集結地（48,16）を16x16の箱で囲って120秒回した。

| | 敵ウォーカーが箱の外に居たティック | 壁の上に居たティック | 敵の家 |
|---|---|---|---|
| 壁なし | 535 | 0 | 7（うち1つは箱の外） |
| 壁あり | **0** | **0** | 6（全て箱の中） |

家の数がほとんど変わらないのは箱が集落を収めるのに十分広いからで、
**この壁が効かせたのは封じ込めであって兵糧攻めではない**。マナは
両陣営とも上限まで届いており、行き止まりで詰む挙動は出ていない。

## 検証

- 641 → 656テスト。`applyWall`（築く／水・亀裂・毒カビには築けない／
  森を伐る／建築不能になる／何も築かなければ0を返す／**地割れが断つ**／
  **溶岩が埋める**）、移動（壁の上に乗らない／端を回り込んで反対側へ
  着く／回り込みを覚えて、開いたら捨てる／**英雄は跨ぐ**／石の中から
  出られる／四方を囲まれたら止まる）
- typecheck / build / `sprites:check` / `palette:check` 通過
- 本番ビルドを静的配信して実機確認。31個のコマンドが並び、城壁が4回
  連続で発動し（毎回12マナ）、壁が石壁として描かれた。その後**地震を
  1発**撃つと壁は半分になった——冷たい灰色の画素数で、詠唱前0 →
  4詠唱後6906 → 地震後3355

## 色の話（実機で1度直した）

最初 `WALL_COLOR` を `GAME_PALETTE.stoneLight` にしたところ、実機の砂漠
地形で**壁が完全に見えなかった**。地形色 `soilLight` が `0x9f8c6d`、
`stoneLight` が `0xa1916f`——3チャンネルとも4以内である。パレットの石は
この世界そのものの色なので、石で壁を塗ると地面になる。冷たい灰色
（`0x8d8f96`）にした。地形色の外から取った唯一の色で、理由は
IsoRenderer.ts のコメントに残した。
