# 平坦化ツールの追加

## 背景

ユーザーからの一連のフィードバックのうち「平地が作りたくてもうまく作れない」
について調査したところ、地形操作は隆起/沈降(±1)のみで、専用の
「平坦化」ツールが存在しないことが分かった。`raiseTile`はタイルの4頂点を
同じ量だけ動かすが、隣接タイルとは頂点を共有しているため、1タイルずつ
±1を繰り返して周囲と高さを合わせる作業は非常に手間がかかり、
きれいな平地を手作業で作るのが難しかった。

## 対応

### `src/world/heightmap.ts`: `flattenTile`

タイルの4頂点を指定した高さ(`elevation`)に一括で揃える関数を新設。
`TerrainEditRule`（隆起のみ/沈降のみ/両方）の制約下でも「まだ平坦化は
可能、方向が制限されるだけ」という既存の設計意図（`TerrainEditRule`の
doc comment）を守るため、禁止されている方向にしか動かせない頂点は
そのまま変更せず放置する（`isTerrainEditAllowed`で判定）。

### `src/main.ts`: 「平坦化」ツール

新しい`ToolMode`として`"flatten"`を追加し、既存の隆起/沈降と同じ
ブラシ（長押し+なぞり）機構に乗せた。目標の高さは、そのブラシ
ストロークが最初に触れたタイルの4頂点から決める:

- 通常(`both`): 4頂点の平均。
- `raiseOnly`: 4頂点の最大値（下げられないので、最も高い頂点に
  合わせて他を持ち上げるしかない）。
- `lowerOnly`: 4頂点の最小値（同様に、最も低い頂点に合わせる）。

一度決めた目標高さはそのブラシストローク中ずっと使い回す
(`flattenTargetElevation`)。そうしないと、なぞった先のタイルごとに
別々の平均・最大・最小へ向かってしまい、結局デコボコのまま複数の
異なる高さの小さな平地ができてしまう。ジェスチャーが終わる
(`stopPainting`)か新しいジェスチャーが始まると目標をリセットする。

コストは既存の`TERRAIN_EDIT_MANA_COST`を流用（隆起/沈降と同じ、
1タイル1マナ）。

`index.html`のツールバーに「◼ 平坦化」ボタンを追加（隆起/沈降/
集結地移動/地震と同じ行）。

## 検証

- `npm run typecheck` / `npm run test -- --run`（417件、`flattenTile`の
  新規テスト5件を含む）/ `npm run build`: すべて成功。
- Playwright（chromium）で実機確認: ズームインした状態で平坦化ツールを
  選択し、起伏のある地形を長押し+なぞりでブラシ操作したところ、
  なぞった範囲全体が単一の高さの平地（芝生のディザー表現つき）に
  変わることを確認。コンソールエラーも無かった。
