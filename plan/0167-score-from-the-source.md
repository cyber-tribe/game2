# 0167 score-from-the-source

## スコアの稼ぎ方を捏造していた

「岩礁のスコアが地下巨石と同額なのはおかしい」を直しに行って、根拠の一行
そのものが**資料に存在しない**と分かった。

`docs/original-miracles.md` はこう書いていた。

> 経験点の稼ぎ方（効果の高い順）：**地下巨石・岩礁を使う**／敵リーダーを
> 倒す／ウォーカー同士の直接戦闘に勝つ／時間が経つ

攻略資料22ページを全文検索した結果:

| 語 | 出現 |
|---|---|
| 効果の高い順 | **0件** |
| 稼ぎ方 | **0件** |
| 時間経過 | **0件** |
| 時間が経つ | 1件（戦闘が一段落するまで待つ話。スコアと無関係） |
| 直接戦闘 | 11件（すべて戦い方の話） |
| 敵リーダーを倒す | 1件（敵のマグネット侵攻への**対処法**） |

資料がスコアの源として名指ししているのは**2つだけ**である。

- 地下巨石「この神技には『**なぜか経験点が非常に高い**』という特徴があるため、
  もっぱら点数稼ぎに使われる」
- 岩礁「**地下巨石ほどではない**がそれなりに経験点が入るので点数稼ぎに」

`plan/0160` はこの偽の一行の上に**4つの源とその順位**を実装し、そのうち
「敵リーダーを倒す」のために `createLeaderLossSystem` を、「直接戦闘に勝つ」
のために `onFightWon` を足していた。

## 直したこと

- `SCORE_VALUE` を **`megalith: 300` / `reef: 120`** の2つにした。同額だった
  のは、岩礁の行にあった「低コストでスコア効率が高い」という**これも偽の
  引用**（`plan/0164` で文書は訂正済み）が根拠だった。資料は逆に
  「地下巨石ほどではない」と書いている。
- **敵リーダー撃破と直接戦闘の勝利を、スコア源から外した。** `onFightWon`
  は他に用途が無いので削除。`createLeaderLossSystem` は残す——「あなたが
  リーダーを失った」は戦いの記録の一行として独立に価値があるし、
  `plan/0160` でこの見張りを書いたときに見つけた「集結がリーダーを吸い込む」
  バグの修正も独立に正しい。
- **時間経過は残すが、game2 のものだと明記した。** 資料は「ただし地下巨石は
  無いので、**他の方法でスコアを確保したい**ところです」（No.34-36）と、
  他の手段があること**だけ**を書いて名前を挙げていない。地下巨石も岩礁も
  配られない面が詰むのを避ける最小の受け皿として置く。10分ぶんで地下巨石
  2回ぶん——名指しされた2つを食わない大きさにしてある。

## 同じ失敗の3件目

1. 岩礁「低コストでスコア効率が高い」——資料にコストの記述は無い（`plan/0164`）
2. 実装済み一覧の「火山→水（埋め立てれば外へ流れ出す）」——未実装だった（`plan/0162`）
3. 経験点の稼ぎ方4項目——存在しない（これ）

3件とも、**この文書に書いた要約を資料そのものだと思ってコードの根拠にした**
ものである。原文に当たれば1回で分かる。`docs/original-miracles.md` の
レベルの節に「原文の引用を並べて書くこと」と明記した。

## ついでに確かめたこと（こちらは正しかった）

同じ節の他の主張を全部原文と突き合わせた。**「持続時間」は表現が違うだけで
正しかった**——資料は「持続時間」という語を使わず、地震「一定時間（**地レベル
が上がるほど長くなる**）」、竜巻・嵐「（**気レベル**が上がるほど）」、火柱
「（**火レベル**が上がるほど）」と書いている。系統の対応まで `plan/0161` の
実装と一致していた。雷の命中精度、毒カビの植物レベル、稲妻マーク10個も逐語で
確認できた。引用を原文に差し替えてある。

## まだ直っていないこと

**経験点はプレイヤーが配分する。** 「経験点を**地と気レベルに重点配分**して
下さい」「**経験点の使い道**に迷ったら水レベルを上げる」——原作は6系統への
割り振りをプレイヤーに選ばせている。`plan/0161` の `awardStage`（使った系統へ
自動で入る）は game2 の発明であり、原作と違う。UIを伴う変更なので別PRにする。
